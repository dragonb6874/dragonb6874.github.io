리코 GR IIIx 레시피 중 ==자연스러운 네거티브 필름 색감== 계열로,
여름에 쓰기 좋은 5개를 골랐다. 기준은 많이들 쓰는 **Reggie's Color Negative**의 결.
(쨍한 슬라이드·흑백은 제외.) 값은 **GR III / GR IIIx 공통**이다.

## 1. Reggie's Color Negative — 만능 기준

흐림·맑음 안 가리는 ==만능형==. 일상·인물·여행 스냅에 두루 무난하다.

| 항목 | 값 |
|---|---|
| Effect | Negative Film |
| 채도 | +2 |
| 색상(Hue) | 0 |
| H/L Key | 0 |
| 콘트라스트 | +3 |
| 콘트라스트(하이라이트) | −4 |
| 콘트라스트(섀도) | −1 |
| 샤프니스 | +1 |
| 명료도 | 0 |
| 하이라이트 / 섀도 보정 | Auto / Medium |
| 화이트밸런스 | 오토 (A:6) · 노출 −1/3~+1/3 |

## 2. Kodak Portra 160 — 따뜻하고 부드러운

==여름 햇살·인물 피부==에 강한 포트라 감성. 크리미한 따뜻한 톤.

| 항목 | 값 |
|---|---|
| Effect | Negative Film |
| 채도 | +3 |
| 색상 | −1 |
| H/L Key | +3 |
| 콘트라스트 | −1 |
| 콘트라스트(하이라이트) | +2 |
| 콘트라스트(섀도) | −3 |
| 샤프니스 | 0 |
| 명료도 | −4 |
| 하이라이트 / 섀도 보정 | Auto / High |
| 화이트밸런스 | 그늘(Shade) A:3 G:3 · 노출 0 |

> 후기: 제작자도 "여름 햇빛에 잘 맞는다"고 함. 인물·따뜻한 일상에 추천.
> 출처: [Luke Taylor](https://www.lukeptaylor.com/blog/portra-160-ricoh-gr-iii-film-simulation)

## 3. Natural Analog — 차분한 자연색

채도를 낮춰 ==녹음·그늘·잔잔한 골목==에 어울리는 차분한 필름 느낌.

| 항목 | 값 |
|---|---|
| Effect | Positive Film |
| 채도 | −3 |
| 색상 | +1 |
| H/L Key | 0 |
| 콘트라스트 | −2 |
| 콘트라스트(하이라이트) | +4 |
| 콘트라스트(섀도) | −2 |
| 샤프니스 | +2 |
| 음영(Shading) | +1 |
| 명료도 | +1 |
| 하이라이트 / 섀도 보정 | On / Medium |
| 화이트밸런스 | 주광(Daylight) A:7 G:1 · 노출 +1/3~+2/3 |
