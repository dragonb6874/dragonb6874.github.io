### GPT-6.1 Terra 출시, GPT-5.6 Terra 대비 가격 50% 인하·API 입력 100만 토큰당 1달러 — OpenAI (10/26)
OpenAI가 **GPT-6.1 Terra**를 공개했다. ChatGPT Work와 Codex에서 Plus·Pro·Enterprise·Edu 사용자에게 순차 제공되고, API에서는 `gpt-6.1-terra`로 쓸 수 있다. API 가격은 100만 토큰당 **입력 1달러·캐시 입력 0.05달러·출력 5달러**이며, OpenAI는 이전 Terra(GPT-5.6)보다 50% 저렴하다고 밝혔다. 자체 오류 유발 프롬프트 평가에서 낮은 추론 강도의 오류율이 53.6%에서 **16.7%**로, 최대 추론 강도에서는 **4.3%**로 내려가 GPT-6 Astra·GPT-6.1 Sol에 근접했다고 설명했다(회사 자체 보고).
출처: [OpenAI (X) — GPT-6.1 Terra 공지](https://x.com/OpenAI/status/2114780720170164735) · [OpenAI Help — Model Release Notes](https://help.openai.com/en/articles/9624314-model-release-notes) · [9to5Mac — OpenAI upgrades ChatGPT and Codex with new GPT-6.1 Terra model](https://9to5mac.com/2026/10/26/openai-upgrades-chatgpt-and-codex-with-new-gpt-6-1-terra-model/)

### Gemini 4 Carbon 공개, 사이버보안·장기 작업 특화 최상위 모델 — Google (10/28)
Google이 **Gemini 4 Carbon**을 공개했다. 사이버보안과 장기(long-horizon) 작업 역량을 내세운 자사 최고 성능 모델이며, 2주 전 나온 Gemini 4 Argon의 후속이다. 이번 주부터 Fairwind Program을 통해 일부 사이버 방어 담당자에게 먼저 제공하고 신뢰 파트너로 단계적으로 넓히며, 개발자·기업·일반 사용자 제공은 "coming soon"이다. 도입 가격은 100만 토큰당 **입력 2달러·출력 10달러**(캐시 입력 95% 할인), 도입 기간 이후에는 입력 4달러·출력 20달러다. Google은 Artificial Analysis Intelligence Index v5.0 1위(59점), SEC-bench Pro 88.2%, ExploitGym 54.8%, CWE-bench 71.0%를 제시했다(회사 자체 보고).
출처: [Google — Gemini 4 Carbon: our next frontier model](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/)

### Mistral Large 4 오픈 웨이트 공개, 에이전틱 코딩·사이버보안 겨냥 — Mistral AI (10/29)
Mistral AI가 10월 초 공개 프리뷰로 낸 **Mistral Large 4**의 가중치를 공개했다. 1조 파라미터 규모의 네이티브 멀티모달 MoE 모델이며 추론 강도는 Low·Medium·High 3단계다. 라이선스는 수정 MIT 계열인 "Mistral Ecosystem Open-Weight license"로, 모델 서비스(MaaS)를 운영하는 기업은 별도 상용 라이선스가 필요하다. Mistral API·Mistral Studio·OpenRouter·Microsoft Foundry와 Hugging Face에서 쓸 수 있고, API 가격은 100만 토큰당 **입력 0.70달러·캐시 입력 0.07달러·출력 2.10달러**다. Mistral은 Terminal-Bench 4.0 41%(프리뷰 대비 +13p), Artificial Analysis Coding Agent Index 48%, Artificial Analysis Cyber Index 51%를 제시했다(회사 자체 보고).

### Claude Code 2.1.311: `ultrathink` xhigh 적용·1M 컨텍스트 오류 시 자동 compaction — Anthropic (10/26)
Anthropic이 Claude Code **2.1.311**을 배포했다. 인터랙티브 터미널의 `ultrathink`가 Opus 5.5·Sonnet 5.5·Haiku 5.5·Fable 5.1에서 해당 턴을 **xhigh effort**로 실행하도록 바뀌었고, 표준 컨텍스트 세션이 200K 토큰을 넘을 때 "Usage credits required for 1M context"로 멈추던 문제는 이제 대화를 compaction한 뒤 이어가도록 고쳤다. `self-hosted-runner`에 `--hold-idle-file`·`--max-hold-min` 옵션이 추가됐고, Bedrock·Mantle·Vertex·Foundry에서는 모델 설정을 downloads.claude.ai의 서명된 파일에서 불러온다(`CLAUDE_CODE_MODEL_CATALOG=off`로 끌 수 있음).

### GitHub Copilot, GitHub App 서버 간(server-to-server) 인증 지원(퍼블릭 프리뷰) — GitHub (10/27)
GitHub가 조직에 설치된 GitHub App이 Copilot SDK로 만든 서비스·에이전트를 **사용자 자격 증명 없이** 조직 단위로 호출할 수 있는 서버 간 인증을 퍼블릭 프리뷰로 내놓았다. 앱에 읽기 전용 Copilot Requests 조직 권한을 주고, 단기 installation access token을 Copilot SDK에 전달하는 방식이다. 사용량은 앱이 설치된 조직에 귀속·과금되며 조직의 모델 정책·예산·지출 제한이 적용된다. 조직 소유자는 AI 사용량 CSV 리포트의 `app_client_id` 필드로 앱별 사용량을 확인하고, 앱을 일시 중지하거나 제거해 접근을 회수할 수 있다.
출처: [GitHub Changelog — GitHub Copilot supports server-to-server authentication](https://github.blog/changelog/2026-10-27-github-copilot-supports-server-to-server-authentication)

### Claude Code 2.1.312: 사용량 한도 문구 "5-hour limit"로 변경·대형 CLAUDE.md 덮어쓰기 버그 수정 — Anthropic (10/27)
Anthropic이 Claude Code **2.1.312**를 배포했다. 출처: [GitHub — anthropics/claude-code Release v2.1.312](https://github.com/anthropics/claude-code/releases/tag/v2.1.312)

### Codex CLI 0.165.0: Vertex AI 내장 provider·GPT-6.1 Terra 모델 카탈로그 추가 — OpenAI (10/27)
OpenAI가 Codex CLI **0.165.0**을 배포했다. 출처: [GitHub — openai/codex Release 0.165.0](https://github.com/openai/codex/releases/tag/rust-v0.165.0)

### GitHub Copilot Fusion 정식 출시, 모델 자동 라우팅·오케스트레이션 — GitHub (10/28)
GitHub가 모델 선택기에서 **Copilot Fusion**을 고르면 작업마다 모델을 라우팅·조합해 주는 기능을 GA로 내놓았다. 노력 수준은 Standard·High·Max 3단계이고, 작업별로 Single(한 모델)·Cascade(효율 모델이 초안, 품질 검사 후 상위 모델로 승격)·Critique(초안·검토·수정) 중 하나로 실행한다. 모든 Copilot 요금제에서 VS Code·Copilot 앱·Copilot CLI·JetBrains에서 쓸 수 있고, 사용한 모델별 표준 요금이 청구된다(한시적으로 유료 플랜 30% 할인). GitHub는 Artificial Analysis Coding Agent Index에서 Fusion Max가 60점으로 Claude Code(Opus 5.5 Max)와 2점 이내였고 작업당 평균 API 비용은 약 절반이라고 밝혔다(회사 자체 보고).
출처: [GitHub Changelog — Route and orchestrate models with GitHub Copilot Fusion](https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion)

### GitHub Agentic Workflows 정식 출시(GA) — GitHub (10/28)
GitHub Next의 오픈소스 프로젝트 **GitHub Agentic Workflows**가 GA가 됐다. 자연어 Markdown으로 정의한 자동화를 Actions YAML로 컴파일해, 이슈 분류·CI 실패 분석·문서 갱신·테스트 작성 같은 작업을 GitHub Actions 안에서 코딩 에이전트로 실행한다. 기본 읽기 전용 권한, 샌드박스 컨테이너와 Agent Workflow Firewall, safe outputs 검증, 위협 탐지 작업이 안전장치로 들어 있다. 프리뷰 이후 self-hosted runner의 ARC·Docker-in-Docker 지원과 모델 라우팅이 추가됐다. github.com의 Free·Team·Enterprise에서 쓸 수 있고, 기본 Copilot CLI 엔진은 Copilot 라이선스가 필요하다.
출처: [GitHub Changelog — GitHub Agentic Workflows generally available](https://github.blog/changelog/2026-10-28-github-agentic-workflows-generally-available)

### Agent Merge, 클라우드에서 PR의 실패 워크플로·머지 충돌 자동 수정 — GitHub (10/28)
GitHub가 PR을 지켜보다가 머지를 막는 요소를 고쳐 주는 **Agent Merge**를 github.com PR에도 통합했다. 머지 박스에서 "Watch and fix"를 고르면 실패한 GitHub Actions 워크플로나 머지 충돌(또는 둘 다)이 생길 때 Copilot이 클라우드 개발 환경에서 작업한다. auto-merge와 함께 쓰면 조건 충족 시 자동 머지되며, 유료 Copilot 요금제와 조직·엔터프라이즈 정책이 적용된다. 기존에 Copilot 앱과 VS Code에서는 이미 쓸 수 있었다.
출처: [GitHub Changelog — Agent Merge watches and fixes pull requests in the cloud](https://github.blog/changelog/2026-10-28-agent-merge-watches-and-fixes-pull-requests-in-the-cloud)

### GitHub Copilot SDK, Microsoft Copilot SDK로 전환 시작 — GitHub (10/28)
GitHub가 **GitHub Copilot SDK**를 Microsoft·GitHub 제품이 공유하는 에이전트 기반인 Microsoft Copilot harness용 프로그래밍 인터페이스, 즉 **Microsoft Copilot SDK**로 바꾸는 작업을 시작했다. 저장소 브랜딩·문서 갱신이 시작됐고 Microsoft 조직으로의 이전은 단계적으로 진행되며 완료 날짜는 밝히지 않았다. 기존 사용자에게 즉시 필요한 변경은 없고 패키지 이름·네임스페이스는 당분간 유지되며 지원 방식도 그대로다.
출처: [GitHub Changelog — GitHub Copilot SDK is becoming Microsoft Copilot SDK](https://github.blog/changelog/2026-10-28-github-copilot-sdk-is-becoming-microsoft-copilot-sdk)

### Codex CLI 0.166.0: 키보드 기반 transcript 선택·검색, `codex doctor --network-only` — OpenAI (10/29)
OpenAI가 Codex CLI **0.166.0**을 배포했다. transcript를 단어·줄·페이지 단위로 키보드로 선택하고 검색할 수 있으며, GPT-6.1 Terra가 번들·Vertex AI·Amazon Bedrock 모델 카탈로그에 들어갔다. 대기열에 메시지를 넣은 뒤 `codex queue --resume`으로 언로드된 스레드를 재개할 수 있고, `codex doctor --network-only`로 네트워크·WebSocket 진단을 할 수 있다. 스레드를 재개·포크해도 승인·권한 설정이 유지되고, 부모 스레드를 복원하면 하위 스레드도 복원되도록 고쳤다.
출처: [GitHub — openai/codex Release 0.166.0](https://github.com/openai/codex/releases/tag/rust-v0.166.0) · [OpenAI — ChatGPT & Codex changelog](https://learn.chatgpt.com/docs/changelog)

### Claude Code 2.1.314: `permissions.blockWritesOutsideWorkingDirectories`·VS Code 유휴 compaction 추가 — Anthropic (10/30)
Anthropic이 Claude Code **2.1.314**를 배포했다. `permissions.blockWritesOutsideWorkingDirectories`를 켜면 Write·Edit·NotebookEdit가 모든 권한 모드에서 작업 디렉터리 밖 경로를 거부한다. VS Code와 Claude Desktop Code 탭에서는 200K 토큰을 넘긴 대화가 유휴 상태일 때 요약하고, 프롬프트 캐시가 만료됐으면 다음 메시지에 그 요약을 쓴다. Claude apps gateway upstream에 `groups` 옵션(IdP 그룹별 라우팅)과 Bedrock용 `guardrail_trace`가 추가됐다. 관리자가 모델의 effort 상한을 제한할 때 "Invalid effort level"로 세션이 실패하던 문제, `claude -p` 시작 실패 시 종료 코드 0으로 끝나던 문제, `.git/index.lock` 오류를 일으키던 백그라운드 diff 갱신을 고쳤다. `FORCE_HYPERLINK=false`는 이제 하이퍼링크를 끈다.
