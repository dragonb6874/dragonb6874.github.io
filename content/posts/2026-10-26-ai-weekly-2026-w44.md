## 🧠 모델 출시

### GPT-6.1 Terra 출시, GPT-5.6 Terra 대비 가격 50% 인하·API 입력 100만 토큰당 1달러 — OpenAI (10/26)
OpenAI가 **GPT-6.1 Terra**를 공개했다. ChatGPT Work와 Codex에서 Plus·Pro·Enterprise·Edu 사용자에게 순차 제공되고, API에서는 `gpt-6.1-terra`로 쓸 수 있다. API 가격은 100만 토큰당 **입력 1달러·캐시 입력 0.05달러·출력 5달러**이며, OpenAI는 이전 Terra(GPT-5.6)보다 50% 저렴하다고 밝혔다. 자체 오류 유발 프롬프트 평가에서 낮은 추론 강도의 오류율이 53.6%에서 **16.7%**로, 최대 추론 강도에서는 **4.3%**로 내려가 GPT-6 Astra·GPT-6.1 Sol에 근접했다고 설명했다(회사 자체 보고).
출처: [OpenAI (X) — GPT-6.1 Terra 공지](https://x.com/OpenAI/status/2114780720170164735) · [OpenAI Help — Model Release Notes](https://help.openai.com/en/articles/9624314-model-release-notes) · [9to5Mac — OpenAI upgrades ChatGPT and Codex with new GPT-6.1 Terra model](https://9to5mac.com/2026/10/26/openai-upgrades-chatgpt-and-codex-with-new-gpt-6-1-terra-model/)

## 🤖 AI 코딩 에이전트

### GPT-6.1 Terra, GitHub Copilot에서 정식 제공 — GitHub (10/26)
GitHub가 **GPT-6.1 Terra**를 Copilot에서 정식(GA) 제공한다고 밝혔다. GPT-6.1 Sol보다 낮은 비용으로 일상적인 에이전트 코딩과 터미널 작업에 맞춘 모델이라고 소개했으며, Copilot Pro·Pro+·Max·Business·Enterprise 요금제에서 VS Code·Visual Studio·Copilot CLI·Copilot 클라우드 에이전트·github.com·JetBrains·Xcode·Eclipse 등의 모델 선택기에서 고를 수 있다(순차 배포). Business·Enterprise 관리자는 Copilot 모델 정책으로 접근을 관리한다.
출처: [GitHub Changelog — GPT-6.1 Terra in GitHub Copilot](https://github.blog/changelog/2026-10-26-gpt-6-1-terra-in-github-copilot)

### Claude Code 2.1.311: `ultrathink` xhigh 적용·1M 컨텍스트 오류 시 자동 compaction — Anthropic (10/26)
Anthropic이 Claude Code **2.1.311**을 배포했다. 인터랙티브 터미널의 `ultrathink`가 Opus 5.5·Sonnet 5.5·Haiku 5.5·Fable 5.1에서 해당 턴을 **xhigh effort**로 실행하도록 바뀌었고, 표준 컨텍스트 세션이 200K 토큰을 넘을 때 "Usage credits required for 1M context"로 멈추던 문제는 이제 대화를 compaction한 뒤 이어가도록 고쳤다. `self-hosted-runner`에 `--hold-idle-file`·`--max-hold-min` 옵션이 추가됐고, Bedrock·Mantle·Vertex·Foundry에서는 모델 설정을 downloads.claude.ai의 서명된 파일에서 불러온다(`CLAUDE_CODE_MODEL_CATALOG=off`로 끌 수 있음).
출처: [GitHub — anthropics/claude-code Release v2.1.311](https://github.com/anthropics/claude-code/releases/tag/v2.1.311)
