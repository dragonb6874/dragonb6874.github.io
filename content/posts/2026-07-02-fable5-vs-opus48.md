Anthropic의 두 프런티어 모델, **Claude Fable 5**와 **Claude Opus 4.8**의 차이를 정리한다.
스펙·가격·동작 방식 위주로, Anthropic 공식 문서에 나온 사실만 담았다.

> ⚠️ 아래 수치는 모두 Anthropic 공식 문서(플랫폼 docs·발표 페이지) 기준. 개인 해석·추론은 넣지 않았다.

## 한눈에 보는 표

| 항목 | Claude Fable 5 | Claude Opus 4.8 |
|---|---|---|
| 포지션 | ==Anthropic 최상위 공개 모델== (Mythos-class) | 복잡한 에이전트 코딩·기업 업무용 |
| API ID | `claude-fable-5` | `claude-opus-4-8` |

| 최대 출력 | 128k 토큰 | 128k 토큰 |
| Adaptive thinking | Yes (**항상 켜짐**) | Yes |
| Extended thinking | No | No |
| 상대 지연(latency) | 느림(Slower) | 보통(Moderate) |
| 지식 컷오프 | Jan 2026 | Jan 2026 |
| 데이터 보존 | ==Covered Model — 30일 보존, ZDR 불가== | (Covered 지정 없음) |
| 출시 | 2026-06-09 | — |

## 1. 포지션 · 성능

Fable 5는 Anthropic이 ==일반 공개한 모델 중 가장 강력한 모델==이다(Mythos-class).
공식 문서 표현으로 "가장 까다로운 추론과 **long-horizon 에이전트 작업**"을 위한 모델이다.

Opus 4.8은 "복잡한 에이전트 코딩과 기업 업무용"으로 소개된다.
Anthropic의 모델 선택 가이드는 이렇게 안내한다:

- **어떤 걸 쓸지 모르겠으면 → Opus 4.8부터 시작**
- **가능한 최고 성능이 필요하면 → Fable 5**

발표 페이지가 든 성능 사례(모두 공식 기준):

- Cognition **FrontierCode** 평가에서 ==중간 effort에서도 프런티어 모델 중 최고 점수==
- Hebbia **Finance Benchmark**에서 모든 모델 중 최고 점수
- 메모리 사용 시 *Slay the Spire* 성능 향상이 ==Opus 4.8 대비 3배==

## 2. 가격 — Fable 5가 정확히 2배

- Fable 5: **$10 / M 입력**, **$50 / M 출력**
- Opus 4.8: **$5 / M 입력**, **$25 / M 출력**

입력·출력 모두 ==Fable 5가 Opus 4.8의 딱 2배==다.
그래서 일상 작업·대량 트래픽은 Opus 4.8이, 길고 복잡한 자율 작업은 Fable 5가 비용 대비 유리하다.

## 3. 사고 방식(thinking)

- Fable 5는 **Adaptive thinking이 항상 켜져 있다.** `thinking: {"type": "disabled"}`를 지원하지 않는다.
  생각 깊이는 `effort` 파라미터로 조절.
- Fable 5는 ==raw chain-of-thought를 반환하지 않는다==. `summarized`(요약) 또는 `omitted`(빈 값, 기본) 중 선택.
- Opus 4.8은 `effort`가 ==모든 환경(API·Claude Code·claude.ai)에서 기본 `high`==.

## 4. 거부(refusal) · 폴백 — Fable 5에만 있는 동작

Fable 5에는 **안전 분류기(safety classifier)** 가 붙어 있어 일부 요청을 거부할 수 있다.

- 거부 시 Messages API는 에러가 아니라 ==HTTP 200 + `stop_reason: "refusal"`== 로 응답
- 거부된 요청은 보통 **다른 Claude 모델(예: Opus 4.8)로 폴백**해 처리 가능 (server-side / client-side / manual)
- 출력 생성 전 거부된 요청은 **과금되지 않음**

Opus 4.8에는 이 분류기 계층이 없다(Messages API 동작이 Fable 5·Mythos 5에만 다르다고 명시).

## 5. 데이터 보존

- Fable 5(및 Mythos 5)는 ==Covered Model== 로 지정되어 **30일 데이터 보존**이 적용되고 **ZDR(zero data retention) 불가**.
  안전 분류기 운용을 위해 프롬프트·출력을 보존해야 하기 때문.
- Opus 4.8은 이 Covered Model 지정이 없다.

## 6. 토크나이저 주의점

Fable 5는 **Opus 4.7에서 도입된 토크나이저**를 쓴다.
4.7 이전 모델과 비교하면 ==같은 텍스트가 약 30% 더 많은 토큰==으로 계산된다.
컨텍스트·비용 추정 시 참고.
