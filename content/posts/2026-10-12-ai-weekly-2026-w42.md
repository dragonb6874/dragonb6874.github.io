## 🧠 모델 출시

### Muse Wonder·Muse Wonder Full 공개, 에이전트용 프런티어 모델·Meta Model API 제공 — Meta (10/12)
Meta가 Muse Spark를 기반으로 한 **Muse Wonder**와 **Muse Wonder Full**을 "지금까지 가장 강력한 모델"로 공개하고, 개인·업무용 에이전트 작업과 메모리·코딩 벤치마크에서 최고 수준 성능을 낸다고 밝혔다. 대화 간 정보를 이어 쓰는 **Active Memory**와 어려운 작업에서도 목표를 유지하며 중요한 단계 전에 확인을 구하는 **Active Focus**를 내세웠고, Prometheus 데이터센터에서 학습했다. Muse Wonder는 **Meta Model API**와 코딩 에이전트 **Muse Code**에서 바로 쓸 수 있으며(TechCrunch 보도 기준 입력 100만 토큰당 4달러·출력 20달러), Muse Wonder Full은 Muse Code 구독자 전용이다.
출처: [Meta — Introducing Muse Wonder and Muse Wonder Full: Frontier Models for Agents](https://about.fb.com/news/2026/10/introducing-muse-wonder-models/) · [Meta AI Research 블로그 — Muse Wonder](https://research.meta.ai/blog/muse-wonder) · [TechCrunch — Meta releases its first frontier model, Muse Wonder](https://techcrunch.com/2026/10/12/meta-releases-its-first-frontier-model-muse-wonder/)

### Gemini 4 Argon 전면 제공, Gemini API·Gemini 앱(Pro·Ultra)·Antigravity로 확대 — Google (10/13)
Google이 9월 30일 신뢰 사이버 방어자 대상으로 먼저 공개한 **Gemini 4 Argon**을 API를 통해 전 세계 개발자·기업에 제공하기 시작했다. Gemini API 유료 티어(AI Studio·Android Studio), Gemini 앱과 검색 AI 모드(Google AI Pro·Ultra 구독자), Google Antigravity(Ultra 구독자), Gemini for business에서 쓸 수 있으며, API 가격은 **11월 30일까지 도입가 입력 100만 토큰당 2달러·출력 10달러**(캐시 입력 95% 할인), 이후 4달러·20달러다. 사이버 가드레일 없는 버전을 순차 제공하는 Fairwind 프로그램은 수백 곳의 파트너로 확대했다.
출처: [Google 블로그 — Gemini 4 Argon: Built to solve your hardest problems](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/) · [Google 블로그 — Gemini 4 Argon is now available for developers](https://blog.google/innovation-and-ai/technology/developers-tools/build-with-gemini-4-argon/) · [VentureBeat — Google makes Gemini 4 Argon broadly available](https://venturebeat.com/technology/google-makes-gemini-4-argon-broadly-available-with-limited-time-low-api-pricing-of-2-10-per-1m-token)

## 🤖 AI 코딩 에이전트

### Codex '28일 매일 개선' 7일차, Codex·ChatGPT Work의 GPT-6.1 Sol 기본 컨텍스트 272k→500k 토큰 확대 — OpenAI (10/11)
OpenAI Codex 책임자 Thibault Sottiaux가 X에서 28일 개선 7일차로 **Codex·ChatGPT Work를 통해 쓰는 GPT-6.1 Sol의 기본 컨텍스트 길이를 272k에서 500k 토큰으로(약 80% 증가) 늘렸다**고 밝혔다. 컴팩션 발생을 줄이고 오랜 시간 많은 맥락과 뉘앙스를 유지해야 하는 작업을 돕기 위한 조치로, 사용자는 GPT-6.1 Sol의 최대치인 **100만 토큰**까지 직접 높이거나 낮출 수 있다.
출처: [Thibault Sottiaux (X) — Day 7](https://x.com/thsottiaux/status/2109430343346581527) · [OpenAI Developer Community — 28 days of Shipping at OpenAI](https://community.openai.com/t/28-days-of-shipping-at-openai/1403897)

### Gemini 4 Argon, GitHub Copilot에 정식 탑재 — GitHub (10/13)
GitHub가 **Gemini 4 Argon**을 Copilot **Pro+·Max·Business·Enterprise** 요금제에 정식(GA) 제공한다고 밝혔다. VS Code·Visual Studio·JetBrains IDE·Xcode·Eclipse, Copilot CLI, Copilot 코딩 에이전트, GitHub Copilot 앱의 모델 선택기에서 고를 수 있으며, 사용량 기반 과금에서 제공사 정가로 청구되고 순차 배포된다. Business·Enterprise 관리자는 Copilot 설정의 모델 정책으로 접근을 관리한다.
출처: [GitHub Changelog — Gemini 4 Argon in GitHub Copilot](https://github.blog/changelog/2026-10-13-gemini-4-argon-in-github-copilot)

## 🛠️ 도구 · 벤치마크

### 자체 소스 관리 시스템 'Scion'·코드 리뷰 도구 'Antique' 설계 공개, 모노레포에서 git 대체 — Anthropic (10/13)
Anthropic이 엔지니어링 블로그에서 모노레포의 git을 대체한 자체 소스 관리 시스템 **Scion**과 코드 리뷰 도구 **Antique**를 소개했다. 하루 머지 수가 2026년 5월 약 2,500건에서 9월 **3만 건 이상**으로 늘자 7명이 5개월 만에 개발·이전을 마쳤으며, 항상 연결된 클라이언트(주로 에이전트·CI)를 전제로 이력·blame·커밋·머지·리베이스를 서버에서 처리한다. 기존 git 미러링 대비 CPU·메모리 사용량이 **약 200분의 1**이고 CI·연구 작업 체크아웃이 분 단위에서 초 단위로 줄었다고 밝혔다. Scion은 "일반 용도의 git 대체품이 아니다"라며 오픈소스로 공개하지 않고 설계 내용만 공유했다.
출처: [Anthropic 엔지니어링 — Redesigning source control at Anthropic](https://www.anthropic.com/engineering/redesigning-source-control)

### Origin 앱 마켓플레이스 공개 제출 개방, 배포·CI·코드 리뷰·보안 등 20여 개 앱 연동 — Cursor (10/13)
Cursor가 자체 코드 호스팅 서비스 **Origin**이 배포·CI·코드 리뷰·보안·모니터링·프로젝트 관리 분야 **20개 이상 앱**(Cloudflare·Vercel·Buildkite·CodeRabbit·Semgrep·Sentry·Linear 등)과 연동된다고 밝히고, 앱 마켓플레이스를 개발 도구 팀의 공개 제출에 열었다. 앱은 Origin API(앱 JWT·설치 액세스 토큰·웹훅)로 체크 런·PR 코멘트·리뷰를 작성할 수 있으며, 데모 영상과 함께 제출하면 Cursor 심사 후 등재된다.
출처: [Cursor Changelog — Origin App Marketplace](https://cursor.com/changelog/origin-app-marketplace) · [SiliconANGLE — Cursor launches Origin code hosting service](https://siliconangle.com/2026/08/17/cursor-launches-origin-code-hosting-service-to-compete-with-github/)

## 🏗️ 인프라

### Azure Maia 300 공개, TSMC N2P·HBM4 288GB·Maia 200 대비 랙 단위 토큰 처리량 최대 7배 — Microsoft (10/12)
Microsoft가 3세대 자체 AI 가속기 **Maia 300**의 아키텍처를 공개했다. 연산 다이는 **TSMC N2P** 공정이고 가속기당 **HBM4 8스택(288GB, 18TB/s)**을 탑재하며, 167kW 랙 하나에 **96개**(Maia 200의 2배 밀도)를 넣어 Maia 200 대비 **랙 단위 토큰 처리량 최대 7배**·와트당 성능 2.5배 이상이라고 밝혔다. 멀티스텝 에이전트 실행·롱컨텍스트 디코딩 등 에이전트형 추론을 겨냥했으며, 대상 서비스로 Microsoft Copilot·GitHub Copilot·Microsoft Foundry를 꼽았다.
출처: [Azure 블로그 — Deep dive into Azure Maia 300 architecture](https://azure.microsoft.com/en-us/blog/deep-dive-into-azure-maia-300-architecture/) · [UPI — Microsoft announces new AI chip Azure Maia 300](https://www.upi.com/Top_News/US/2026/10/12/microsoft-azure-maia-300-ai-chips-nvidia/3511791823960)

### OCP 글로벌 서밋, Vera Rubin 랙·컴퓨트 트레이 설계 OCP 기여·MGX 1.2 사양 제출 — NVIDIA (10/12)
NVIDIA가 산호세 OCP Global Summit에서 **Vera Rubin 랙·컴퓨트 트레이 설계**를 MGX 아키텍처를 통해 OCP에 기여하고, 블라인드메이트 액체냉각·5,000A 버스바·최대 250kW 랙을 지원하는 **MGX 1.2 사양**과 에이전트의 도구 호출·샌드박스 실행용 **Vera CPU 랙 사양**을 제출했다고 밝혔다. 아울러 AMD·Google·Meta와 AI 팩토리 시설 설계 청사진 **Open Data Center Specification v0.7**을, Google·Meta·Microsoft와 전력망 교란 시 2초 이내에 거의 전 부하로 복구하는 기준을 담은 **OCP Grid Resilience Specification**을 공동 발표했다.
출처: [NVIDIA 블로그 — OCP Global Summit: NVIDIA Opens Vera Rubin Architecture to Help Scale AI Factories](https://blogs.nvidia.com/blog/ocp-global-summit-vera-rubin-scale-ai-factories/)

### Helion 공개, 랙당 최대 32,768 CPU 코어 에이전트 AI용 오픈 랙 레퍼런스 설계 — AMD (10/12)
AMD가 OCP Global Summit에서 에이전트 AI용 랙 스케일 레퍼런스 설계 **Helion**을 공개했다. 6세대 EPYC만으로 **랙당 최대 32,768 CPU 코어**를 넣는 CPU 전용 구성과, EPYC CPU 노드에 **Instinct MI350P** GPU 노드를 결합한 올인원 구성이 있으며 액체냉각·공랭 버전을 제공한다. Helion 사양은 OCP에 기여할 계획이고, Cisco·Dell·HPE·Lenovo·Supermicro 등 파트너와 개발 중인 구성은 **2026년 11월** 출시 예정이다.
출처: [AMD 뉴스룸 — Introducing AMD Helion, Agentic AI Compute at Rack Scale](https://newsroom.amd.com/news/open-rack-blueprint-scale-agentic-ai/) · [Tom's Hardware](https://www.tomshardware.com/pc-components/cpus/amd-debuts-helion-reference-design-for-agentic-ai-servers-with-up-to-32-768-zen-6-venice-cores-rack-design-ships-next-year-in-cpu-only-and-all-in-one-configurations)
