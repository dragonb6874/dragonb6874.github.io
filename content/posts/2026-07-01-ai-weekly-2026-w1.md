## 🤖 AI 코딩 에이전트

### Codex CLI 0.142.0 메이저 릴리스 — OpenAI (6/22)

`/usage` 개선, 플러그인 탐색, **토큰 예산 설정**, 멀티에이전트 위임 제어, 인덱스 웹검색 모드 추가.
([Codex Changelog](https://developers.openai.com/codex/changelog))

### Codex Remote 정식 출시(GA) — OpenAI (6/25)

ChatGPT 모바일 앱에서 연결된 Mac/Windows 호스트의 작업을 시작·이어가고 승인할 수 있다.
기기-호스트 간 **QR 페어링**과 DigitalOcean 프로비저닝 플러그인을 도입했다.
([Codex Changelog](https://developers.openai.com/codex/changelog))

### GitHub Copilot CLI, Claude Sonnet 5 지원 — GitHub (6/30)

Copilot CLI v1.0.67이 ==Claude Sonnet 5를 모델 옵션으로 추가==하고 샌드박스 제어를 즉시 적용하도록 개선.
v1.0.66은 Claude Opus 4.8 Fast를 지원.
([GitHub Changelog](https://github.blog/changelog/))

### GitHub Copilot, Kimi K2.7 Code 정식 지원(GA) — GitHub (7/1)

==Copilot 모델 선택기에 처음 추가된 오픈웨이트 모델==. 저비용 옵션으로 VS Code에서 선택 가능하며 Pro/Pro+/Max부터 순차 배포, Business·Enterprise는 관리자 정책 활성화 필요.
([GitHub Changelog](https://github.blog/changelog/2026-07-01-kimi-k2-7-is-now-available-in-github-copilot/))

### Cursor Teams 요금 구조 개편 — Cursor (7/1 시행)

Standard 좌석 사용량을 **Composer/Auto(자사 모델)** 와 **Third-Party API(Claude·GPT·Gemini)** 두 풀로 분리.
신규 고객은 즉시, 기존 고객은 7/1부터 갱신 시 적용.
([출처](https://www.developersdigest.tech/blog/ai-coding-tools-pricing-june-2026))

### GitHub Copilot 에이전트 세션 스트리밍 공개 프리뷰 — GitHub (7/2)

Enterprise Cloud에서 모든 클라이언트의 Copilot 사용 데이터(프롬프트·응답·툴 호출)를 **스트리밍 엔드포인트 또는 REST API**로 수집할 수 있다. AI 사용 거버넌스·감사 목적.
([GitHub Changelog](https://github.blog/changelog/2026-07-02-copilot-agent-session-streaming-is-now-in-public-preview/))

### GitHub Copilot CLI, GitHub Actions에서 PAT 불필요 — GitHub (7/2)

Copilot CLI가 GitHub Actions에서 개인용 액세스 토큰(PAT) 대신 내장 `GITHUB_TOKEN`으로 인증한다. 장기 PAT 생성·저장 없이 대규모 자동화의 운영·보안 위험을 제거.
([GitHub Changelog](https://github.blog/changelog/2026-07-02-copilot-cli-no-longer-needs-a-personal-access-token-in-github-actions/))
