### Claude Fable 5 주간 포함 접근 7/19까지 연장 — Anthropic (7/12)

7/7 종료 예정이던 **Fable 5 주간 사용 포함**(플랜별 주간 한도의 최대 50%) 정책을 **7월 19일(오후 11:59:59 PT)까지 연장**했다. Pro·Max·Team·seat 기반 Enterprise 프리미엄 좌석에 적용되며, **Claude Code의 주간 rate limit 50% 상향**도 같은 날까지 함께 연장된다. 별도 신청·토글 없이 웹·모바일·데스크톱·Cowork·Claude Code(2.1.170+)에서 즉시 적용된다. 이후에는 사용 크레딧(100만 토큰당 입력 $10 / 출력 $50) 전환 또는 다른 Claude 모델로 폴백해야 한다.
([Android Authority — Claude Fable 5 promotion extended](https://www.androidauthority.com/claude-fable-5-free-extension-3685103/))

## 🤖 AI 코딩 에이전트

### Claude Code 2.1.208 업데이트 — Anthropic (7/14)

Claude Code **2.1.208**이 접근성·기업 런처·안정성을 개선했다. 평문(plain-text) 렌더링을 제공하는 **스크린 리더 모드**(opt-in)를 추가하고, 커스텀 vim 키 리맵을 위한 `vimInsertModeRemaps` 설정과 기업 런처 통합용 `CLAUDE_CODE_PROCESS_WRAPPER` 지원을 넣었다. 컨텍스트 윈도 추적, 백그라운드 세션 신뢰성, 대형 마크다운 표 렌더링 성능 관련 수정도 포함됐다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Claude Code 2.1.209 업데이트 — Anthropic (7/14)

Claude Code **2.1.209**는 2.1.208에서 잘못 제한됐던 **백그라운드 세션의 대화상자 차단(dialog blocking)** 문제를 되돌리는 소규모 버그 수정 릴리스다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Claude Code 2.1.210 업데이트 — Anthropic (7/15)

Claude Code **2.1.210**이 진행 가시성·보안·안정성을 개선했다. 접힌 도구 요약에 **실시간 경과 시간 카운터**를 표시하고, `Write(path)`·`NotebookEdit(path)` 같은 구식 권한 규칙 사용 시 시작 경고를 띄운다. **격리된(isolated) 서브에이전트가 메인 저장소 체크아웃에 git 변경 명령을 실행하던 문제**를 수정했고, `ultracode` 키워드가 webhook 페이로드 등 자동 입력에서 오발동하지 않도록 고쳤다. 도구 결과 렌더링 크래시·훅 콜백 타임아웃 등 세션 안정성 수정도 포함됐다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Claude Code 2.1.211 업데이트 — Anthropic (7/16)

Claude Code **2.1.211**이 서브에이전트 관측성·보안·안정성을 개선했다. 서브에이전트의 텍스트·사고(thinking)를 stream-json 출력에 포함하는 `--forward-subagent-text` 플래그(및 `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` 환경변수)를 추가했고, 채팅 채널로 전달되는 **권한 미리보기에서 양방향 재정의·제로폭·유사 따옴표 문자를 무력화**해 도구 입력이 승인 메시지를 시각적으로 변조하지 못하도록 막았다. auto 모드가 비샌드박스 Bash에 대한 PreToolUse 훅의 `ask` 결정을 덮어쓰던 문제, Vertex·Bedrock에서 명시적으로 모델을 지정했는데도 기본 Opus를 시도하던 문제, Bedrock·Vertex·Mantle·Foundry 프롬프트 캐싱 회귀, `/clear` 시 세션 비용 카운터가 리셋되지 않던 문제 등도 수정했다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

## 🛠️ 도구 · 벤치마크

### Claude for Teachers 출시 — Anthropic (7/14)

Anthropic이 미국 K-12 교사를 위한 무료 AI 어시스턴트 **Claude for Teachers**를 공개했다. 인증된 교사에게 프리미엄 Claude 기능과 학습과학 기반 교수(teaching) 스킬을 제공하고, **Learning Commons**를 통해 미 50개 주 학업 표준에 매핑된 근거 기반 커리큘럼(OpenSciEd·Illustrative Mathematics IM v.360 등)에 연결해 표준에 맞춘 수업안·차별화 지도·학급 데이터 분석을 돕는다. 2027년 6월 30일까지 가입 시 1년 무료.
([Anthropic — Introducing Claude for Teachers](https://www.anthropic.com/news/claude-for-teachers))
