## 🧠 모델 출시

### Claude Fable 5 주간 포함 접근 7/19까지 연장 — Anthropic (7/12)

7/7 종료 예정이던 **Fable 5 주간 사용 포함**(플랜별 주간 한도의 최대 50%) 정책을 **7월 19일(오후 11:59:59 PT)까지 연장**했다. Pro·Max·Team·seat 기반 Enterprise 프리미엄 좌석에 적용되며, **Claude Code의 주간 rate limit 50% 상향**도 같은 날까지 함께 연장된다. 별도 신청·토글 없이 웹·모바일·데스크톱·Cowork·Claude Code(2.1.170+)에서 즉시 적용된다. 이후에는 사용 크레딧(100만 토큰당 입력 $10 / 출력 $50) 전환 또는 다른 Claude 모델로 폴백해야 한다.
([Android Authority — Claude Fable 5 promotion extended](https://www.androidauthority.com/claude-fable-5-free-extension-3685103/))

### Inkling 오픈 웨이트 모델 공개 — Thinking Machines Lab (7/15)

Thinking Machines Lab이 자체 학습한 첫 모델 **Inkling**을 오픈 웨이트로 공개했다. 총 **975B 파라미터 / 활성 41B**의 Mixture-of-Experts 구조로 최대 **1M 토큰 컨텍스트**를 지원하며, 텍스트·이미지·오디오·비디오 45조 토큰으로 사전학습돼 텍스트·비전·오디오를 네이티브로 추론한다(출력은 텍스트·코드·구조화 데이터 등). 가중치는 Hugging Face에 원본 체크포인트와 NVIDIA Blackwell용 NVFP4 변형으로 공개됐고, 총 276B/활성 12B의 **Inkling-Small** 프리뷰도 함께 제공된다. 회사는 공지에서 "Inkling is not the strongest overall model available today, open or closed"라고 밝히며 자사 파인튜닝 플랫폼 Tinker용 커스터마이징 베이스로 위치를 규정했다.
([Thinking Machines Lab — Inkling: Our open-weights model](https://thinkingmachines.ai/news/introducing-inkling/))

### Kimi K3 공개 — Moonshot AI (7/16)

Moonshot AI가 플래그십 모델 **Kimi K3**를 공개했다. 총 **약 2.8조 파라미터** 규모의 sparse Mixture-of-Experts 구조로 **1M 토큰 컨텍스트**, 네이티브 비전, 상시 추론("thinking mode")을 지원하며, 내부 개발한 Kimi Delta Attention(하이브리드 linear attention)·Attention Residuals 기법을 적용했다. **K3 Max·K3 Swarm Max**로 제공되고 가격은 100만 토큰당 입력 $3 / 출력 $15, **모델 가중치는 7월 27일 오픈 예정**으로 공개 시 역대 최대 오픈 웨이트 모델이 된다. Moonshot은 자체 벤치마크에서 Anthropic **Fable 5와 경쟁력 있는(competitively)** 성능을 보였고 Opus 4.8·GPT-5.6를 상회했다고 주장했으나, 이는 외부 검증 전 벤더 자체 수치다.
([VentureBeat — China's Moonshot AI releases Kimi K3, the largest open-source model ever](https://venturebeat.com/technology/chinas-moonshot-ai-releases-kimi-k3-the-largest-open-source-model-ever-rivaling-top-u-s-systems))

## 🤖 AI 코딩 에이전트

### Claude Code 2.1.208 업데이트 — Anthropic (7/14)

Claude Code **2.1.208**이 접근성·기업 런처·안정성을 개선했다. 평문(plain-text) 렌더링을 제공하는 **스크린 리더 모드**(opt-in)를 추가하고, 커스텀 vim 키 리맵을 위한 `vimInsertModeRemaps` 설정과 기업 런처 통합용 `CLAUDE_CODE_PROCESS_WRAPPER` 지원을 넣었다. 컨텍스트 윈도 추적, 백그라운드 세션 신뢰성, 대형 마크다운 표 렌더링 성능 관련 수정도 포함됐다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Claude Code 2.1.209 업데이트 — Anthropic (7/14)

Claude Code **2.1.209**는 2.1.208에서 잘못 제한됐던 **백그라운드 세션의 대화상자 차단(dialog blocking)** 문제를 되돌리는 소규모 버그 수정 릴리스다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Claude Code 2.1.210 업데이트 — Anthropic (7/15)

Claude Code **2.1.210**이 진행 가시성·보안·안정성을 개선했다. 접힌 도구 요약에 **실시간 경과 시간 카운터**를 표시하고, `Write(path)`·`NotebookEdit(path)` 같은 구식 권한 규칙 사용 시 시작 경고를 띄운다. **격리된(isolated) 서브에이전트가 메인 저장소 체크아웃에 git 변경 명령을 실행하던 문제**를 수정했고, `ultracode` 키워드가 webhook 페이로드 등 자동 입력에서 오발동하지 않도록 고쳤다. 도구 결과 렌더링 크래시·훅 콜백 타임아웃 등 세션 안정성 수정도 포함됐다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Claude Code 2.1.211 업데이트 — Anthropic (7/16)

Claude Code **2.1.211**이 서브에이전트 관측성·보안·안정성을 개선했다. 서브에이전트의 텍스트·사고(thinking)를 stream-json 출력에 포함하는 `--forward-subagent-text` 플래그(및 `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` 환경변수)를 추가했고, 채팅 채널로 전달되는 **권한 미리보기에서 양방향 재정의·제로폭·유사 따옴표 문자를 무력화**해 도구 입력이 승인 메시지를 시각적으로 변조하지 못하도록 막았다. auto 모드가 비샌드박스 Bash에 대한 PreToolUse 훅의 `ask` 결정을 덮어쓰던 문제, Vertex·Bedrock에서 명시적으로 모델을 지정했는데도 기본 Opus를 시도하던 문제, Bedrock·Vertex·Mantle·Foundry 프롬프트 캐싱 회귀, `/clear` 시 세션 비용 카운터가 리셋되지 않던 문제 등도 수정했다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Claude Code 2.1.212 업데이트 — Anthropic (7/17)

Claude Code **2.1.212**가 세션 관리·리소스 제한·안정성을 개선했다. `/fork`가 대화를 **새 백그라운드 세션**(`claude agents` 목록의 별도 행)으로 복사해 원래 작업을 계속하도록 바뀌었고, 기본 auto-mode 설정을 되돌리는 `claude auto-mode reset`(확인 프롬프트 포함)을 추가했다. **세션당 WebSearch 호출 상한(기본 200, 환경변수로 조정)**과 **서브에이전트 생성 상한(기본 200, 환경변수 재정의)**을 도입했고, 2분을 넘긴 MCP 도구 호출은 자동으로 백그라운드로 이동하며, 에이전트 뷰에서 `/resume` 입력 시 과거 세션 선택기를 연다. plan 모드 권한·worktree 생성·훅 인프라·SIGTERM 처리·PowerShell·mTLS 인증서 설정 호스티드 세션 시작 실패 등 다수 버그도 수정했다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Claude for Teachers 출시 — Anthropic (7/14)

Anthropic이 미국 K-12 교사를 위한 무료 AI 어시스턴트 **Claude for Teachers**를 공개했다. 인증된 교사에게 프리미엄 Claude 기능과 학습과학 기반 교수(teaching) 스킬을 제공하고, **Learning Commons**를 통해 미 50개 주 학업 표준에 매핑된 근거 기반 커리큘럼(OpenSciEd·Illustrative Mathematics IM v.360 등)에 연결해 표준에 맞춘 수업안·차별화 지도·학급 데이터 분석을 돕는다. 2027년 6월 30일까지 가입 시 1년 무료.
([Anthropic — Introducing Claude for Teachers](https://www.anthropic.com/news/claude-for-teachers))

## 🏗️ 인프라

### Louisiana Hyperion 데이터센터 5GW·500억 달러로 확대 — Meta (7/13)

Meta가 루이지애나 Richland Parish의 **Hyperion** AI 데이터센터를 **5GW IT 용량, 총 500억 달러 이상** 규모로 확대한다고 발표했다. 2025년 10월 Blue Owl Capital과 합작 당시 공개된 2GW·270억 달러에서 두 배 이상 커진 것으로, 부지는 약 1,000만 제곱피트에 이른다. 2030년까지 2GW, 2032년경 5GW 완공을 목표로 하며, 도로·상하수도 등 지역 인프라에 10억 달러 이상을 추가 투입하고 운영 시 약 1,000개(피크 건설 7,500개) 일자리를 예상한다.
([Louisiana Economic Development — Meta commits more than $50 billion for North Louisiana project](https://www.opportunitylouisiana.gov/news/meta-commits-more-than-50-billion-for-north-louisiana-project-becoming-one-of-the-largest-data-centers-in-history))
