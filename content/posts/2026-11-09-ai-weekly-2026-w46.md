## 🧠 모델 출시

### Claude Fable 5.2 · Claude Mythos 5.2 공개 — Anthropic (11/9)
Anthropic이 **Claude Fable 5.2**와 **Claude Mythos 5.2**를 공개했다. 두 모델은 같은 기반 모델이며, Fable은 사이버·생물학 안전장치를 갖춰 모든 사용자가 쓸 수 있고 Mythos는 검증된 조직에만 열린다. 모델 ID는 `claude-fable-5-2`이고 AWS·Google Cloud·Azure에서도 제공한다. 가격은 입력 100만 토큰당 8달러, 출력 40달러(fast mode는 16달러/80달러)이며, Anthropic은 출력이 Fable 5.1·Mythos 5.1보다 최대 30% 빠르다고 밝혔다. Anthropic이 제시한 Opus 5.5 대비 수치는 FrontierCode 2.0 49.1%(45.5%), FrontierSWE v2 69.9%(62.3%), Humanity's Last Exam(도구 사용) 74.2%(67.7%)다.
출처: [Anthropic — Introducing Claude Fable 5.2 and Claude Mythos 5.2](https://www.anthropic.com/claude-fable-and-mythos-5-2)

### Meta, Muse Ember 공개 — Meta (11/9)
Meta Superintelligence Labs가 가장 가볍고 비용 효율이 높은 모델 **Muse Ember**를 공개했다고 TechCrunch가 보도했다. 도구 호출, 코딩 하위 작업, 라우팅, 데이터 추출, 긴 문서 파싱 같은 에이전트 작업이 대상이며 텍스트·이미지·오디오를 입력으로 받는다. 입력 가격은 100만 토큰당 0.10달러이고, Muse 계열의 네 번째 모델이다. 접근 방법(API·오픈 웨이트 여부)은 해당 기사에 나와 있지 않다.
출처: [TechCrunch — Meta releases Muse Ember, a new lightweight model for agent execution](https://techcrunch.com/2026/11/09/meta-releases-muse-ember-a-new-lightweight-model-for-agent-execution/)

### Gemini 4 Carbon 공개 — Google (11/10)
Google이 프런티어 모델 **Gemini 4 Carbon**을 공개했다. 코딩·리서치·다단계 에이전트 작업용이다. Google AI Studio와 Gemini for business의 API로 유료 개발자·기업이 쓸 수 있고, Google AI Ultra 구독자에게는 Antigravity, Gemini 앱, 검색 AI Mode에서 순차 제공한다. 가격은 입력 100만 토큰당 2달러, 출력 10달러(Gemini 4 Argon과 동일)이며 11/30부터 4달러/20달러가 된다. Google은 CursorBench 4.0 등에서 1위라고 밝혔다. Antigravity에서는 한 번의 프롬프트로 에이전트 팀을 조율하는 `/swarm`을 프리뷰로 선보였다.
출처: [Google — Gemini 4 Carbon now available](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/)

### MiniMax H3-Image 공개 — MiniMax (11/11)
MiniMax가 오픈 웨이트 이미지 생성 모델 **H3-Image**를 공개했다. 텍스트-이미지 생성, 참조 이미지 기반 생성, 이미지 편집을 지원하며 최대 16장의 참조 이미지를 받는다. MiniMax는 4K(4096×4096) 이미지를 10초 안에 생성한다고 밝혔다. MiniMax API Platform, MiniMax Code, Hailuo AI에서 쓸 수 있고 가중치는 Hugging Face에 공개했다.
출처: [MiniMax — MiniMax H3-Image](https://www.minimax.io/blog/minimax-h3-image)

## 🤖 AI 코딩 에이전트

### Claude Code 2.1.321: Claude Fable 5.2가 기본 Fable 모델로 — Anthropic (11/9)
Anthropic이 Claude Code **2.1.321**을 배포했다. Claude Fable 5.2(`claude-fable-5-2`)가 기본 Fable 모델이 됐고(1M 컨텍스트), 저장된 Fable 5.1 선택은 `fable`로 옮겨진다(`/model claude-fable-5-1`로 되돌릴 수 있음). `claude remote-control`에 `--settings <file>` 옵션이 추가됐다. MCP OAuth 요청이 리다이렉트 시 다른 호스트로 리프레시 토큰 등 비밀 값을 보내던 문제와, 읽기 전용 Bash 명령이 권한 확인 없이 샌드박스 밖에서 실행되던 문제 등이 수정됐다.
출처: [GitHub — anthropics/claude-code Release v2.1.321](https://github.com/anthropics/claude-code/releases/tag/v2.1.321)

### Claude Fable 5.2, GitHub Copilot에서 정식 제공 — GitHub (11/9)
GitHub가 Copilot에서 **Claude Fable 5.2**를 정식 제공한다고 밝혔다. Copilot Pro+, Max, Business, Enterprise에서 VS Code, Visual Studio, Copilot CLI, Copilot 코딩 에이전트, github.com, 모바일, JetBrains, Xcode, Eclipse 모델 선택기로 고를 수 있으며 롤아웃은 점진적이다. 사용량 기반 과금으로 제공자 정가가 적용된다. Business·Enterprise는 관리자가 정책을 켜야 하고(기본 꺼짐), 기본적으로 데이터 보존이 필요하다.
출처: [GitHub Changelog — Claude Fable 5.2 in GitHub Copilot](https://github.blog/changelog/2026-11-09-claude-fable-5-2-in-github-copilot)

### Claude Code 2.1.322: Vertex에서 fast mode 지원 — Anthropic (11/10)
Anthropic이 Claude Code **2.1.322**를 배포했다. Vertex의 global, us, eu 리전에서 fast mode를 쓸 수 있게 됐다. Vertex가 fast mode 요청을 거부하면 표준 속도로 되돌아간다.
출처: [GitHub — anthropics/claude-code Release v2.1.322](https://github.com/anthropics/claude-code/releases/tag/v2.1.322)

### Gemini 4 Carbon, GitHub Copilot에서 정식 제공 — GitHub (11/10)
GitHub가 Copilot에서 Google의 **Gemini 4 Carbon**을 정식 제공한다고 밝혔다. 복잡한 코딩·에이전트·추론 작업용 모델로 소개했다. Copilot Pro+, Max, Business, Enterprise에서 VS Code, Visual Studio, Copilot CLI, Copilot 코딩 에이전트, Copilot 앱, github.com, 모바일, JetBrains, Xcode, Eclipse 모델 선택기로 고를 수 있으며 롤아웃은 점진적이다. 사용량 기반 과금으로 제공자 정가가 적용되고, Business·Enterprise는 관리자가 모델 정책으로 접근을 관리한다.

### Codex 0.167.2: Vertex AI에서 도구 업데이트 증분 전송 — OpenAI (11/11)
OpenAI가 Codex(rust) **0.167.2**를 배포했다. Google Cloud Vertex AI에서 Codex가 도구 업데이트를 기본으로 증분 전송한다. 이전 방식으로 돌리려면 `config.toml`의 `[features]`에서 `incremental_tools_legacy_gcp = false`로 설정한다.
출처: [GitHub — openai/codex Release rust-v0.167.2](https://github.com/openai/codex/releases/tag/rust-v0.167.2)

### Claude Code 2.1.323: 실험적 Code Mode 추가 — Anthropic (11/12)
Anthropic이 Claude Code **2.1.323**을 배포했다. Claude가 JavaScript를 써서 도구를 호출하는 **Code Mode**가 실험적 옵트인 기능으로 들어왔다. 플러그인은 `plugin.json`의 `engines["claude-code"]`로 지원 버전 범위를 지정할 수 있고, 긴 훅이 `claude -p`·SDK 세션에서 멈춘 것으로 처리되지 않도록 30초마다 진행 신호를 보낸다. Write/Edit가 `Read` deny 규칙이 걸린 경로에 쓰지 못하도록 막는 등 권한·보안 수정도 포함됐다. 알 수 없는 모델 ID의 컨텍스트 윈도우 기본값은 200K에서 1M으로 바뀌었다.
출처: [GitHub — anthropics/claude-code Release v2.1.323](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)

## 🛠️ 도구 · 벤치마크

### Secret scanning, GitHub Actions 워크플로 로그의 시크릿 탐지(퍼블릭 프리뷰) — GitHub (11/9)
GitHub가 워크플로 실행이 끝나면 Actions 로그에서 제공자 패턴 시크릿을 검사하는 기능을 퍼블릭 프리뷰로 내놨다. 발견 사항은 저장소의 secret scanning 알림 목록에 로그 링크와 함께 표시되고, 로그를 삭제해도 알림은 남는다. GitHub Secret Protection 또는 Advanced Security가 있는 GitHub Enterprise Cloud에서 쓸 수 있으며, 엔터프라이즈 정책에서 켜야 한다(기본 꺼짐). 기능을 켠 뒤 끝난 실행만 검사하고 알림 통지(notification)는 보내지 않는다.
출처: [GitHub Changelog — Secret scanning detects secrets in GitHub Actions workflow logs](https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs)

## 🏗️ 인프라

### Nvidia·SK텔레콤·Rebellions, GPU-NPU 통합 시스템 개발 MOU — Nvidia 외 (11/9)
Nvidia, SK텔레콤, Rebellions가 11/9 서울 "Nvidia AI Day Seoul 2026"에서 한 데이터센터 안에서 Nvidia GPU와 Rebellions NPU를 함께 운용하는 통합 시스템 개발 MOU를 맺었다. Rebellions의 차세대 R200 NPU를 NVLink Fusion으로 연결하고 Nvidia MGX 랙에 통합하며, SK텔레콤은 자체 인프라에서 시스템 검증을 지원한다. 상용 배포 목표 시점은 2028년이다.
출처: [Seoul Economic Daily — Nvidia to Run Korean AI Chips Alongside Its GPUs in Data Centers](https://en.sedaily.com/finance/2026/11/09/nvidia-to-run-korean-ai-chips-alongside-its-gpus-in-data)

### Google, 8세대 TPU 변종 2종(TPU 8tx · TPU 8i Max) 공개 — Google (11/10)
Google이 4월에 공개한 8세대 TPU의 변종 두 가지를 내놨다고 TechCrunch가 보도했다. **TPU 8tx**는 AMD와 함께 TPU 8t를 바탕으로 만들었고, 하드웨어 계층에 보안을 넣어 AI 모델을 기밀 상태로 학습·실행하는 용도다. **TPU 8i Max**는 TPU 8i 두 개를 한 패키지로 묶어 메모리 용량·연산 성능·대역폭을 TPU 8i의 두 배로 늘렸다. 출시 시점과 가격은 기사에 나와 있지 않다.
출처: [TechCrunch — Google broadens its AI hardware portfolio with two new specialized chips](https://techcrunch.com/2026/11/10/google-broadens-its-ai-hardware-portfolio-with-two-new-specialized-chips/)

### CoreWeave, 고객 선불·단기 계약으로 성장 자금 조달 — CoreWeave (11/11)
CoreWeave가 2026년 3분기 실적 발표에서 매출 36.6억 달러(전년 대비 168% 증가), 순손실 7.09억 달러, 수주 잔고 1,325억 달러를 밝혔다고 TechCrunch가 보도했다. 향후 3개월간 고객 선불·보증금이 약 90억 달러 들어올 것으로 예상하며, 무담보 부채 시장 대신 특정 고객 계약을 담보로 한 대출을 쓰겠다고 밝혔다. 단기 계약은 가격을 올리고(7월 약 25%, 이후 추가 10%) 4~5년 계약은 메가와트당 연 2,000만~2,500만 달러 수준이다.
출처: [TechCrunch — CoreWeave turns to customer prepayments, shorter contracts to fund AI growth](https://techcrunch.com/2026/11/11/coreweave-turns-to-customer-prepayments-shorter-contracts-to-fund-ai-growth/)

### Fractile, 7.2억 달러 시리즈 C 유치 — Fractile (11/11)
영국의 AI 추론 칩 스타트업 Fractile이 7.2억 달러 규모 시리즈 C를 유치했다고 TechCrunch가 보도했다. Thrive Capital, Founders Fund, Lightspeed Venture Partners, Redpoint가 주도했고 영국 Sovereign AI Fund도 참여했다. 칩 위에 DRAM을 쌓는 설계이며, 첫 칩과 시스템은 내년 출하할 계획이다.
출처: [TechCrunch — With $720M round, Britain's Fractile gets a leg up in the race for AI chips](https://techcrunch.com/2026/11/11/with-720m-round-britains-fractile-gets-a-leg-up-in-the-race-for-ai-chips/)

### Nebius, 2027년 설비투자 400억 달러 계획 — Nebius (11/12)
Nebius가 3분기 실적 발표(11/12)에서 2027년 설비투자(capex) 약 400억 달러를 계획한다고 밝혔다고 TechCrunch가 보도했다. 고객 선불과 투자등급 계약 담보 대출로 capex의 최대 85%를 충당할 계획이다. 3분기 매출은 9.81억 달러이고, 제3자 운영 부지 지연으로 2026년 매출 전망을 30억 달러로 2억 달러 낮췄다. 2027년 매출은 120억~130억 달러로 전망했다.
출처: [TechCrunch — Nebius tests the neocloud playbook with $40 billion in planned spending](https://techcrunch.com/2026/11/12/nebius-tests-the-neocloud-playbook-with-40-billion-in-planned-spending/)
