### Muse Glimmer 30B 오픈 모델 공개 — Meta (8/10)

Meta Superintelligence Labs가 **30B 파라미터 오픈 웨이트 모델 Muse Glimmer**를 **Apache 2.0 라이선스**로 Hugging Face에 공개했다. **소비자용 GPU 1장(또는 Mac)에서 구동 가능한 로컬 에이전트용 모델**로, 도구 호출(tool-calling)·장시간 에이전트 작업·코딩·LLM-as-judge 용도로 설계됐으며, 상위 모델 **Muse Spark의 logit distillation**으로 사전학습 후 에이전트 특화 SFT·RL·on-policy distillation을 거쳤다. 4-bit 양자화 버전은 20GB 미만으로 줄어 24–32GB 메모리 환경에서 전체 구동이 가능하고, vLLM·llama.cpp·Ollama·LM Studio·MLX·ExecuTorch·SGLang을 지원한다.
([Meta — Muse Glimmer 공식 페이지](https://developer.meta.com/ai/models/muse-glimmer/) · [SiliconANGLE](https://siliconangle.com/2026/08/10/meta-releases-open-source-muse-glimmer-model-30b-parameters/))

## 🤖 AI 코딩 에이전트

### Claude Code auto mode 기본값 전환 발표 — Anthropic (8/7)

Anthropic이 Claude Code의 **auto mode를 Pro·Max·Team 플랜 기본값으로 전환**한다고 발표했다. **8월 14일부터 새 세션에 적용**되며, 단계마다 승인을 받는 대신 **되돌리기 어렵거나 파괴적이거나 환경 밖을 겨냥한 행동만 확인**을 요청하고, 해당 플랜에선 classifier 오버헤드 과금도 없앤다. 근거로 공개한 자체 데이터에 따르면 사용자는 권한 프롬프트의 **97%를 반사적으로 승인**하며, **유료 사용자 1,053명 테스트에서 auto mode는 위험 명령의 89%를 차단**한 반면 수동 검토는 13.6%에 그쳤고, production 수준 심각도 기준 의도치 않은 피해 포함 세션은 수동 승인 6.3% 대 auto mode 2.4%였다. **720건의 prompt injection 공격 시도는 Fable 5·Opus 5·Sonnet 5 auto mode에서 전부 실패**했다고 밝혔다. 데이터 유출 차단 **hard deny rule**, 비밀정보 접근 구분 규칙, 파괴적 작업 전 git 상태 확인, 외부 콘텐츠 prompt injection 스크리닝이 함께 들어간다. **Enterprise·API·Bedrock 등은 opt-in을 유지**하며 향후 전환 예정이다.
([Anthropic — Auto mode by default in Claude Code](https://claude.com/blog/auto-mode-default-in-claude-code) · [TechCrunch](https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/))

## 🏗️ 인프라

### Source Foundry에 4억 달러 투자 — Situational Awareness (8/8)

전 OpenAI 연구원 **Leopold Aschenbrenner**가 이끄는 AI 헤지펀드 **Situational Awareness**가 반도체 스타트업 **Source Foundry에 4억 달러를 투자**한 사실이 보도됐다. 기존 1억 달러 투자에 더해 **총 투자액은 5억 달러**가 된다. Source Foundry는 Stanford 연구자 **Abdulmalik Obaid·Joe Burg**가 작년 창업한 회사로, **기존보다 단순하고 저렴하고 빠른 반도체 제조 공정**을 개발해 AI 컴퓨트 수요와 칩 생산능력 사이 격차를 줄이는 것을 목표로 하며 Sequoia Capital의 기존 투자를 받았다. 이번 투자는 Situational Awareness가 7월 말 보유 기술주 급락으로 담보 요구에 몰려 **공개 포트폴리오 대부분을 Citadel에 매각(운용자산 200억→100억 달러)한 직후** 이뤄졌다. 펀드는 Anthropic 지분은 그대로 보유하고 있다.
([Bloomberg — Situational Awareness's Mystery Investment Was to Source Foundry](https://www.bloomberg.com/news/articles/2026-08-08/situational-awareness-s-mystery-investment-was-to-source-foundry) · [TechCrunch](https://techcrunch.com/2026/08/09/embattled-hedge-fund-situational-awareness-invests-400m-in-chip-startup-source-foundry/))

### 150억 달러 보통주 공모 발표 — Intel (8/10)

Intel이 **150억 달러 규모 보통주 공모(underwritten public offering)**를 발표했다. 인수단은 30일간 **추가 22.5억 달러** 매수 옵션을 갖는다. 조달 자금은 설비투자·운전자본을 포함한 일반 기업 목적에 사용될 예정으로, Intel은 **AI 컴퓨트 투자로 인한 강한 수요**를 배경으로 들며 2026년 설비투자 전망을 기존 180억 달러에서 **약 200억 달러로 상향**했고 2027년에도 의미 있는 증가를 예고했다.
([Intel Newsroom — Intel Announces Proposed $15 Billion Common Stock Offering](https://newsroom.intel.com/corporate/intel-announces-proposed-15-billion-common-stock-offering) · [CNBC](https://www.cnbc.com/2026/08/10/intel-intc-stock-offering-ai.html))
