## 🤖 AI 코딩 에이전트

### Claude Code 2.1.317: `/schedule` 커넥터 경고·계정 이메일 전송 전 확인, 서브에이전트 effort 변경 — Anthropic (11/3)
Anthropic이 Claude Code **2.1.317**을 배포했다. `/schedule`로 만든 클라우드 예약 작업에 요청하지 않은 커넥터가 붙으면 경고하고, 웹·셸 도구 호출이 계정 이메일 주소를 네트워크로 보내기 전에 먼저 묻는다. Agent SDK 훅 콜백에 `onFailure: "block"`이 추가돼 콜백이 실패하면 동작을 막으며, Claude apps gateway 관리 API에는 기간별 비용 보고서(`GET /v1/organizations/analytics/cost`)가 들어갔다. 다른 모델을 쓰는 서브에이전트·팀원은 세션이 아니라 해당 모델의 저장된(또는 기본) effort 수준을 쓰도록 바뀌었고, `claude -p`가 디스크 가득 참·쿼터 초과로 기록을 잃어도 0으로 종료하던 문제는 오류를 출력하고 1로 종료하도록 고쳤다. Read 도구의 "file unchanged since your last Read" 스텁은 제거됐다.
출처: [GitHub — anthropics/claude-code Release v2.1.317](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)

### GitHub Copilot, JetBrains Air에서 사용 가능 — GitHub (11/3)
GitHub가 **JetBrains Air**에서 Copilot을 쓸 수 있다고 밝혔다. Agent Client Protocol 기반이며, Air의 에이전트 선택기에서 GitHub Copilot을 골라 기존 Copilot 구독으로 로컬 작업과 클라우드 작업을 맡길 수 있다. 클라우드 작업은 Air Teams를 통해 격리된 환경(새 가상 머신의 Docker 컨테이너)에서 실행되고 JetBrains AI 크레딧이 아니라 Copilot 요금제 사용량을 쓴다. 클라우드 작업에는 Air Teams가 켜진 JetBrains 비즈니스 조직 계정과 Air 관리자의 Copilot 활성화가 필요하며, Air의 거버넌스·분석은 Copilot 사용량을 다루지 않고 Air 안에서 Copilot 지출 한도를 설정할 수 없다.
출처: [GitHub Changelog — GitHub Copilot is now available in JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air)

### Claude Code 2.1.318: 로그인 만료 표시, 백그라운드 서브에이전트 셸 3분 후 백그라운드 전환 — Anthropic (11/4)
Anthropic이 Claude Code **2.1.318**을 배포했다. `claude auth status`와 `claude -p` JSON 출력이 저장된 claude.ai 로그인의 만료 시점을 알려 주고, `claude -p` 텍스트 출력은 만료 10일 전부터 stderr에 경고한다. 백그라운드 서브에이전트는 셸 명령이 3분을 넘기면 모든 제공자에서 백그라운드로 옮긴다. `claude -p`는 유효한 JSON이 아닌 `~/.claude.json`을 기본값으로 덮어쓰지 않고, 실패하면서 복구 방법을 안내한다. 또 IDE 터미널에서 시작할 때 IDE 확장을 더 이상 설치·업데이트하지 않으며, 바깥 터미널에서 `/ide`를 쓰라고 안내한다.
출처: [GitHub — anthropics/claude-code Release v2.1.318](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)

### GitHub Copilot, Xcode 코딩 어시스턴트에서 사용 가능(퍼블릭 프리뷰) — GitHub (11/4)
GitHub가 Copilot을 **Xcode의 내장 코딩 어시스턴트**에서 쓸 수 있다고 밝혔다. 퍼블릭 프리뷰이며 Xcode 27.3 베타부터 지원한다. Xcode > Settings > Intelligence에서 설정하고, macOS Tahoe 26.6 이상과 Copilot 요금제(모든 요금제 지원)가 필요하다. 기존 GitHub Copilot for Xcode 확장은 별도 옵션으로 그대로 남는다.
출처: [GitHub Changelog — GitHub Copilot is now available in Xcode's coding assistant](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant)

### Gemini CLI v0.67.0: `models` 명령·`--list-models` 플래그 추가, IDE 컴패니언 컨테이너 샌드박스 연결 — Google (11/4)
Google이 Gemini CLI **v0.67.0**을 배포했다. 모델 탐색용 `models` 명령과 `--list-models` 플래그가 추가됐고, IDE 컴패니언이 exec stdio를 통해 컨테이너 샌드박스에 연결할 수 있다. 프로젝트 지출 한도 오류는 종료성 쿼터 오류로 처리하며, 비대화형 모드는 종료 신호를 처리하고 취소 이후에는 도구를 실행하지 않는다. 함수 호출이 있는 모든 모델 턴에 thought signature를 붙이고, 파일 원자적 쓰기는 읽기 전용 파일과 하드 링크를 존중한다.
출처: [GitHub — google-gemini/gemini-cli Release v0.67.0](https://github.com/google-gemini/gemini-cli/releases/tag/v0.67.0)

### Cursor, "Build Live Apps in Cursor" 공개 — Cursor (11/5)
Cursor가 클라우드 에이전트에게 앱을 요청하면 웹 앱을 만들어 링크로 공유할 수 있는 기능을 공개했다. 필요하면 Postgres 데이터베이스를 구성하고 Cursor SSO 로그인과 호스팅을 처리하며, 외부 시스템 접근에 필요한 비밀 값은 요청한다. 게시 전에 노출된 자격 증명 등을 찾는 자동 보안 점검을 통과해야 하고 명시적으로 게시해야 공개된다. 팀 관리자는 모든 앱과 비밀 값을 볼 수 있고 게시를 승인하거나 취소할 수 있다. 클라우드 에이전트가 켜진 모든 유료 요금제에서 쓸 수 있고, 배포는 Cursor Origin과 GitHub를 지원하며 GitLab 지원은 예정이다.
출처: [Cursor Changelog — Build Live Apps in Cursor](https://cursor.com/changelog/build-live-apps)

### Codex CLI 0.167.0: 에이전트 커맨드 센터(`codex agents --no-daemon`), 백엔드 전환, Vertex AI 설정 마법사 — OpenAI (11/6)
OpenAI가 Codex CLI **0.167.0**을 배포했다. `codex agents --no-daemon`으로 에이전트 커맨드 센터를 열 수 있고, 커맨드 센터와 세션 선택기가 읽지 않은 결과를 표시한다. 터미널 세션 선택기에서 연결된 백엔드를 바꿔도 작성 중인 초안이 유지되며, `gcp_setup_wizard`를 켜면 Google Cloud Vertex AI를 Application Default Credentials 또는 자격 증명 파일로 설정할 수 있다. 모델 제공자를 바꿔도 저장된 대화가 보이고, `Ctrl+L`은 화면만 지우며 이전 메시지는 `Ctrl+T`로 볼 수 있다.
출처: [GitHub — openai/codex Release rust-v0.167.0](https://github.com/openai/codex/releases/tag/rust-v0.167.0)

### Claude Code 2.1.319: MCP 태스크 백그라운드 처리, `permissions.denyInsteadOfPrompting` 설정 추가 — Anthropic (11/6)
Anthropic이 Claude Code **2.1.319**를 배포했다. MCP 서버가 도구 호출을 태스크로 실행하면 터미널에서 즉시 백그라운드로 옮기고 끝났을 때 결과를 Claude에 알린다. 권한 프롬프트를 기다리게 될 도구 호출을 거부하고 턴을 이어 가는 `permissions.denyInsteadOfPrompting` 설정과, 텔레메트리 없이 기능 플래그 조회만 끄는 `CLAUDE_CODE_DISABLE_FEATURE_FLAGS` 환경변수가 추가됐다. `/claude-api latency-optimize`가 추가됐고, auto mode에서 안전 점검을 쓸 수 없어 `claude -p`가 작업을 거부하면 0이 아니라 1로 종료하도록 고쳤다.
출처: [GitHub — anthropics/claude-code Release v2.1.319](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)

### Cursor, "Voice Chat with Agents" 공개 — Cursor (11/6)
Cursor가 에이전트와 실시간 음성 대화를 하는 기능을 공개했다. Agents Window, IDE, 웹, iOS 앱에서 쓸 수 있고, 음성 에이전트가 코딩 요청을 채팅 에이전트에게 넘기며 작업 중에도 진행 상황이나 diff를 물을 수 있다. Grok Voice 기반이고 Privacy Mode를 켜면 데이터 보존 없이(zero data retention) 동작한다. 받아쓰기(dictation)와는 별개 기능이다.
출처: [Cursor Changelog — Voice Chat with Agents](https://cursor.com/changelog/voice-chat)

### GitHub @GitHub, Slack·Teams에서 정식 출시(GA) — GitHub (11/6)
GitHub가 Slack과 Microsoft Teams의 **@GitHub** 연동을 정식 출시했다. 대화를 벗어나지 않고 버그 조사, 이슈 생성, 변경 구현, 풀 리퀘스트 생성을 할 수 있다. Teams에는 구현 계획·코드 변경·미리보기를 대화 옆에서 검토하는 Canvas가 추가됐고, 메시지에서 저장소를 식별해 바로 세션을 시작한다. @GitHub가 만든 이슈·PR 설명에는 "Created from a Slack/Teams conversation with @username"이 붙는다.
출처: [GitHub Changelog — @GitHub in Slack and Teams is generally available](https://github.blog/changelog/2026-11-06-github-copilot-in-slack-and-teams-is-generally-available)

### GitHub Actions, 12월 2일부터 `pull_request_target` 기본 차단 — GitHub (11/2)
GitHub가 12월 2일부터 Actions 이벤트 정책이 명시적으로 허용하지 않으면 `pull_request_target` 워크플로 이벤트를 **기본 차단**한다고 공지했다. 기존 시행일은 11월 2일이었다. 그때까지는 차단될 실행을 보여 주기만 하는 평가 모드로 동작하며, 11월 9일과 16일(각 16:00–18:00 UTC)에 브라운아웃을 실시해 이 시간에는 차단 대상 실행이 오류로 실패한다. GitHub Free·Team·Enterprise Cloud의 **퍼블릭 저장소**가 대상이고, 프라이빗·내부 저장소와 GitHub Enterprise Server는 해당되지 않는다.
출처: [GitHub Changelog — pull_request_target blocked by default December 2](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)

### AMD 2026년 3분기 실적: 데이터센터 매출 85억 4,600만 달러, 전년 대비 97% 증가 — AMD (11/3)

출처: [AMD — Form 8-K (2026-11-03) 3분기 실적 발표](https://www.sec.gov/Archives/edgar/data/0000002488/000000248826000188/q32026991.htm)
