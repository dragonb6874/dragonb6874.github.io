## 🧠 모델 출시

### S1 로보틱스 파운데이션 모델 공개 — Skild AI (8/25)

영상 시연 1개만 보고 처음 보는 작업을 파인튜닝 없이 수행하는 **인컨텍스트 학습(in-context learning) 로봇 파운데이션 모델 S1**을 공개했다. 언어 지시 대신 **비디오 프롬프트**로 작업을 정의하며, 사전학습에서 본 적 없는 **최대 10분 길이의 롱호라이즌 작업**까지 처리한다. 학습 10만 시간 기준 미학습 작업 성공률은 **인컨텍스트 66% vs 언어 프롬프트 9%**였고, 시연 1개가 사후학습 에피소드 약 380개에 해당한다고 밝혔다. 현재 일부 산업 파트너에 우선 배포 중이다.
([Skild AI — Introducing S1: In-Context Learning for Robotics](https://www.skild.ai/blogs/s1))

## 🤖 AI 코딩 에이전트

### Codex CLI 0.149.1 릴리스 — OpenAI (8/24)

0.149.0에 이은 패치 릴리스로, **원격 compaction 시 유지되는 이미지에 예산을 적용**하고, exec 호출자가 새 스레드를 분류할 수 있게 했으며, 분리된(detached) 메모리 요청을 **메모리 통합(consolidation) 요청으로 식별**하도록 바꿨다.
([openai/codex — Release rust-v0.149.1](https://github.com/openai/codex/releases/tag/rust-v0.149.1))

### Claude Code v2.1.243 릴리스 — Anthropic (8/24)

`/usage`에 **Loops 분석**(루프별 실행 횟수·총 토큰·실행당 토큰·마지막 실행)이 추가돼 과도하게 도는 `/loop` 작업을 찾을 수 있다. `/model` 선택기를 순서·라벨이 지정된 목록으로 재구성하는 **`modelPicker`** 설정, 메인 대화는 1시간·서브에이전트는 5분 캐시로 나눠 쓰는 **`promptCacheTtl`·`subagentPromptCacheTtl`**, 조직 계약 단가를 `/cost`·상태줄·텔레메트리에 반영하는 **`modelPricing`** 관리 설정이 들어갔다. API 키를 허용하지 않는 조직을 위한 **Anthropic Console 키리스 로그인**, `/status`의 `Skipped sources` 줄도 추가됐다. 비대화형(`-p`)·SDK 세션에서 원격 MCP 서버가 연결이 끊긴 뒤 복구되지 않던 문제는 자동 재연결로 수정됐다.
([anthropics/claude-code — CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### GitHub Copilot 앱 Customize 탭 정식 출시(GA) — GitHub (8/25)

Copilot 앱의 커스터마이징 항목을 한 화면에 모은 **Customize 탭**이 GA로 전환됐다. **MCP 서버·플러그인·스킬·캔버스**를 카테고리별로 탐색하고, 인기 MCP 서버와 추천 캔버스를 골라 팀의 도구·프로세스에 맞춰 Copilot을 구성할 수 있다.
([GitHub Changelog — GitHub Copilot app Customize tab is generally available](https://github.blog/changelog/2026-08-25-github-copilot-app-customize-tab-is-generally-available))

### Claude Code v2.1.245 · v2.1.246 릴리스 — Anthropic (8/25)

v2.1.245는 **glibc 2.44 기반 리눅스 배포판**(Arch·CachyOS·Fedora Rawhide)에서 실행 즉시 crash 나던 문제를 고쳤다. v2.1.246은 `/permissions`에 **Auto mode 분류기 규칙 탭**을 추가하고, `Bash(git * main)`처럼 서브커맨드 앞에 와일드카드를 둔 allow 규칙에 **시작 시 경고**를 띄운다 — 서브커맨드 앞에 삽입된 옵션까지 매칭되기 때문이다. `--strict-mcp-config` 세션이 로드하지도 않을 `.mcp.json` 서버 승인을 물어 백그라운드 세션이 멈추던 문제, 서드파티 게이트웨이(`ANTHROPIC_BASE_URL`)용 API 키가 Anthropic 텔레메트리 요청에 실려 나가던 문제도 수정됐다. `/cd` 이후 새 디렉터리의 설정·훅·스킬·에이전트가 `--resume` 없이 즉시 적용되도록 개선됐다.
([anthropics/claude-code — CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

## 🛠️ 도구 · 벤치마크

### 모바일 온디바이스 소형 모델 인텔리전스·추론 벤치마크 공개 — Artificial Analysis (8/24)

휴대폰에서 구동 가능한 소형 모델을 대상으로 한 **인텔리전스 및 추론 성능 벤치마크**를 시작했다. 인텔리전스는 **BFCL(도구 호출)·IFBench(지시 이행)·AA-Omniscience(지식/할루시네이션)·GPQA Diamond·MATH-500** 5종으로 측정하고, 모델은 `llama.cpp`로 4비트 이하 양자화한 뒤 **8K 컨텍스트 KV 캐시 포함 8GB 이내**에 들어가야 대상이 된다. 추론 속도·지연·메모리 측정은 **Liquid AI**와 협력해 실제 단말(iPhone 17 Pro)에서 수행한다. 출시 시점 최고 평균 점수는 **Nanbeige4.2-3B와 LFM2.5-2.6B가 63점** 동률, Ornith-1.0-9B 62점, Qwen3.5 9B(Reasoning) 61점이었다.
([Artificial Analysis — Intelligence at pocket scale](https://artificialanalysis.ai/articles/mobile-phone-intelligence-inference))

### Claude 채팅 · Cowork 메모리 통합 — Anthropic (8/25)

기존에 따로 놀던 채팅과 **Cowork**의 메모리를 **하나의 메모리로 합쳤다**. `Settings > Memory`에서 Claude가 기억한 내용을 Topics 단위로 보고 수정·삭제할 수 있다. **건강·신념 등 민감 주제는 기본적으로 저장하지 않으며**, `Include sensitive topics in memory`를 켜야 포함된다. Free·Pro·Max 플랜은 기본 활성화, Team·Enterprise는 기본 비활성화로 관리자가 도입 시점을 정한다.
([Claude Support — Release notes (2026-08-25)](https://support.claude.com/en/articles/12138966-release-notes))

## 🏗️ 인프라

### 4,000만 달러 시리즈 A·AI 옵티컬 인터커넥트 첫 제품 샘플링 — Quintessent (8/24)

AI 데이터센터용 광 인터커넥트 반도체 기업 Quintessent가 **Cycle Capital 주도로 4,000만 달러 규모 시리즈 A**(초과 청약)를 유치했다. Goldman Sachs XIG-Industry Ventures·Hina Liberty Capital·Susquehanna International Group·InterVest·Safar Partners·Ciena가 신규 투자자로 참여했다. 동시에 첫 제품인 **단일 칩 양자점(quantum dot) 기반 DWDM 콤(comb) 레이저**의 고객 샘플링을 시작했다. 레이저 하나에 바이어스 제어 하나로 정밀 간격의 **8개 파장**을 생성해 AI 클러스터 광 연결을 단순화하는 광원이다.
([Business Wire — Quintessent Raises $40 Million Series A](https://www.businesswire.com/news/home/20260824525357/en/Quintessent-Raises-%2440-Million-Series-A-and-Begins-Sampling-First-Product-for-AI-Optical-Interconnects))

### M6 · M5 Ultra 칩 공개 — Apple (8/25)

**첫 2나노 공정 칩 M6**와 애플 실리콘 최초의 **쿼드 다이(quad-die) 구성 M5 Ultra**를 공개했다. M6는 12코어 CPU(슈퍼 2 + 성능 4 + 효율 6), 뉴럴 가속기를 넣은 12코어 GPU, **듀얼 16코어 뉴럴 엔진**, 최대 170GB/s 메모리 대역폭·32GB 통합 메모리를 갖췄고 새 Mac mini에 들어간다. M5 Ultra는 UltraFusion으로 M5 Max 두 개를 다시 이어 붙인 쿼드 다이로 최대 36코어 CPU·80코어 GPU·32코어 뉴럴 엔진, **1.2TB/s 대역폭**(M3 Ultra 대비 +50%)과 최대 512GB 통합 메모리를 제공하며 새 Mac Studio에 탑재된다.
([Apple Newsroom — Apple introduces M6 and M5 Ultra](https://www.apple.com/newsroom/2026/08/apple-introduces-m6-and-m5-ultra-for-a-big-leap-in-performance-and-ai-compute/))
