## 🤖 AI 코딩 에이전트

### Origin 코드 호스팅 얼리 베타 공개 — Cursor (8/17)

Cursor가 자체 코드 호스팅 서비스 **Origin**을 **유료 플랜 전체 대상 얼리 베타**로 배포하기 시작했다. 저장소·풀 리퀘스트·코드 브라우징·GitHub 동기화를 기본 제공하며, 새 **Codebase 탭**에서 Origin 저장소를 만들고 CLI로 push하면 호스팅된다. 기존 GitHub 저장소도 연결해 나란히 두고 동기화 범위를 선택하거나 언제든 해제할 수 있고, Vercel·Depot·Buildkite 배포/CI 연동을 지원한다. 엔터프라이즈 조직은 관리자가 opt-out할 수 있다.
([Cursor Changelog — Origin Code Hosting](https://cursor.com/changelog/origin-code-hosting))

### Claude Code v2.1.234 · v2.1.235 릴리스 — Anthropic (8/18)

**v2.1.234**는 사용량 한도 리셋 시 **세션 자동 재개**(설정 가능), 푸터·상태줄의 **GitLab 머지 리퀘스트 배지**(draft/pending/green), 관리 환경용 `CLAUDE_CODE_PROJECT_DIR_NAME` 환경변수를 추가하고, Windows NT-namespace 경로를 파일 연산 전반에서 차단했다. 서브에이전트 실행 중 세션 범위 권한이 유실되던 문제도 수정됐다. 같은 날 나온 **v2.1.235**는 맞춤법 오류에 밑줄을 긋는 선택적 `spellcheck` 설정을 추가하고, 언어 서버 연결 해제 시 프롬프트 캐시가 무효화되던 문제와 백그라운드 클라우드 세션의 메모리·CPU 사용을 개선했다.
([anthropics/claude-code — CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### GitHub Copilot for JetBrains 엔터프라이즈 관리 설정 지원 — GitHub (8/18)

JetBrains용 GitHub Copilot 플러그인이 **엔터프라이즈 관리 설정(enterprise managed settings)**을 지원한다. 관리자는 `enabledPlugins`·`strictKnownMarketplaces`로 플러그인과 승인된 마켓플레이스를 통제하고, **`allowedMcpServers`·`deniedMcpServers`로 개발자가 연결 가능한 MCP 서버를 중앙에서 제한**할 수 있다. OpenTelemetry 수집 엔드포인트·프로토콜·콘텐츠 캡처 정책을 중앙 설정으로 개발자 설정보다 우선 적용하며, `permissions.disableBypassPermissionsMode`로 **Bypass Approvals·Autopilot 비활성화**가 가능하다.
([GitHub Changelog — Enterprise managed settings in GitHub Copilot for JetBrains](https://github.blog/changelog/2026-08-18-enterprise-managed-settings-in-github-copilot-for-jetbrains))

## 🛠️ 도구 · 벤치마크

### API 가격 개편·피크/오프피크 요금제 발효 — DeepSeek (8/17)

DeepSeek이 8월 13일 공지한 **V4 API 가격 개편**이 **8월 16일 16:00 UTC(한국시간 8월 17일 오전 1시)**부터 발효됐다. **피크(01:00–04:00·06:00–10:00 UTC)/오프피크 이원 요금제**가 도입돼 오프피크 가격은 피크의 절반이며, V4-Pro 출력은 100만 토큰당 **0.87달러 → 피크 3.96·오프피크 1.98달러**, V4-Flash 출력은 **0.28달러 → 피크 1.32·오프피크 0.66달러**, V4-Pro 캐시 히트 입력은 0.0036달러 → 피크 0.044달러로 모델·토큰 종류·시간대에 따라 **50~1,100% 인상**됐다. Reuters는 인상 후에도 주요 경쟁사 대비 낮은 수준이라고 전했다.
([DeepSeek API Docs — Change Log](https://api-docs.deepseek.com/updates/) · [Reuters — DeepSeek raises API pricing for its V4 models](https://finance.yahoo.com/technology/ai/articles/deepseek-raises-api-pricing-v4-115712902.html))

### Imagen 4 API 엔드포인트 3종 셧다운 — Google (8/17)

Gemini API의 Imagen 4 standard·ultra·fast 엔드포인트(`imagen-4.0-generate-001`, `imagen-4.0-ultra-generate-001`, `imagen-4.0-fast-generate-001`)가 **8월 17일부로 종료**됐다. 2026년 6월 15일 changelog에서 예고된 일정이며, 공식 문서는 대체 모델로 **Gemini 3.1 Flash Image**를 안내한다.
([Gemini API Docs — Imagen 4](https://ai.google.dev/gemini-api/docs/models/imagen) · [Gemini API — Release notes](https://ai.google.dev/gemini-api/docs/changelog))

### ChatGPT for Teens 출시 — OpenAI (8/18)

OpenAI가 13~17세 대상 전용 경험 **ChatGPT for Teens**를 **8월 18일부터 무료·유료 개인 플랜의 해당 계정에 글로벌 순차 배포**했다(호주는 9월 8일 전면 제공 예정). 사용자가 13~17세라고 밝히거나 **연령 예측(age prediction) 시스템이 18세 미만으로 추정**하면 자동으로 이 모드에 배치된다. 성적·낭만적 롤플레이, 그래픽한 폭력, 자해 등 민감 콘텐츠 노출을 기본값으로 제한하고 감정·의식이 있다는 암시를 억제하며, 답을 바로 주지 않고 힌트·단계별 안내·확인 질문으로 유도하는 **Study Mode**, 학습용 시작 프롬프트, 퀴즈, 그리고 Quiet Hours·안전 알림 등 보호자 제어를 포함한다.
([OpenAI — Introducing ChatGPT for Teens](https://openai.com/index/chatgpt-for-teens/) · [TechCrunch — OpenAI launches a safer ChatGPT for teens](https://techcrunch.com/2026/08/18/openai-launches-a-safer-chatgpt-for-teens-years-after-teens-started-using-it/))

### 풀스택 agentic commerce 플랫폼 공개 — Alipay (8/18)

Alipay가 항저우 파트너 콘퍼런스에서 **중국 최초의 풀스택 agentic commerce 플랫폼**을 공개했다. 가맹점을 Alipay의 소비자 AI 에이전트 **Ah Bao**(2026년 6월 출시)에 연결하고, **AHA 프로토콜**로 서로 다른 에이전트·기기 간 상호운용을 지원하며 결제·신원확인·리스크 관리·주문이행을 통합한다. Ah Bao는 대화로 공과금 납부, 반려동물 서비스 예약, EV 충전소 검색 등 1만 개 이상 생활 서비스를 제공하고 KFC·미쉐(Mixue)·루이싱커피 등이 연동됐으며, 점유율 합계 70% 이상인 스마트폰 5개 브랜드 및 자동차 제조사 16곳과 연결됐다고 밝혔다.
([TNGlobal — Alipay launches agentic commerce platform in China](https://technode.global/2026/08/18/alipay-launches-agentic-commerce-platform-in-china-to-bring-ai-tools-to-merchants/) · [Alipay 공식 X](https://x.com/Alipay/status/2089353045620523141))

### 오하이오 PORTS-Pike 데이터센터 계약, Nvidia 최대 1,050억 달러 보증 — OpenAI·Nvidia·SB Energy (8/17)

OpenAI가 오하이오주 파이크 카운티 **PORTS-Pike Technology Campus**에서 약 **8GW-IT** 규모 용량을 쓰는 계약을 체결했다. 소프트뱅크 산하 **SB Energy**가 캠퍼스를 건설·소유·운영하며 리스 기간은 20년, 초기 용량은 4.25GW로 2028년 800MW 1단계 가동이 예정됐다. **Nvidia는 리스·전력 지불 의무를 최대 1,050억 달러까지 보증**하고 SB Energy에 15억 달러를 투자하며, OpenAI는 지역사회 기금 4,000만 달러와 오하이오 대학생 대상 Codex 크레딧 8,400만 달러를 내놓는다.
([OpenAI — OpenAI joins PORTS-Pike project](https://openai.com/index/openai-joins-ports-pike-project/) · [Reuters — Nvidia to provide up to $105 billion guarantee for OpenAI's Ohio data center](https://finance.yahoo.com/technology/ai/articles/nvidia-invest-1-5-billion-124300582.html))

### 7억 달러 조달·210억 달러 밸류에이션, Jane Street 첫 인도 완료 — Etched (8/18)

AI 추론 전용 칩 스타트업 Etched가 **Jane Street 주도로 7억 달러를 조달**하며 기업가치 **210억 달러**를 인정받았다. Kleiner Perkins·Sequoia·a16z·Tiger Global·Bain Capital Ventures·Blackstone 등이 참여했으며, 7월 시리즈 C(103억 달러)에서 **한 달 만에 밸류에이션이 두 배**가 됐다. Etched는 저전압 prefill 칩과 decode용 클러스터 규모 메모리 인터커넥트를 묶은 **"frontier inference cluster"** 형태의 시스템을 공급하며, 이번 라운드를 이끈 Jane Street가 **첫 랙 시스템을 자사 데이터센터에 설치·검증**했다고 발표했다.
([GlobeNewswire — Etched Raises $700M at a $21B Valuation and Completes First Customer Delivery to Jane Street](https://www.globenewswire.com/news-release/2026/08/18/3347095/0/en/etched-raises-700m-at-a-21b-valuation-and-completes-first-customer-delivery-to-jane-street.html) · [TechCrunch — Etched's valuation doubles to $21B in a month](https://techcrunch.com/2026/08/18/etcheds-valuation-doubles-to-21b-in-a-month/))
