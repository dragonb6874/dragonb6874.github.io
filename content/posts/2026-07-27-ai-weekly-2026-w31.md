### Kimi K3 오픈웨이트·기술 리포트 공개 — Moonshot AI (7/27)

Moonshot AI가 **Kimi K3의 전체 모델 가중치와 기술 리포트**를 공개했다. **총 2.8조 파라미터 중 토큰당 1,040억 개가 활성화**되는 MoE 모델로, 896개 전문가 중 16개를 선택하는 **Stable LatentMoE** 구조에 **Kimi Delta Attention(KDA)**과 **Attention Residuals(AttnRes)**를 적용했다. **1M 토큰 컨텍스트**와 텍스트·이미지·비디오 네이티브 멀티모달을 지원하고, **MXFP4 가중치 + MXFP8 활성값** 양자화 인식 학습(QAT)을 썼다. 공개된 벤치마크는 GPQA Diamond 93.5, DeepSWE 67.5, Terminal-Bench 88.3, BrowseComp 91.2, MMMU-Pro 81.6/83.4다. 가중치와 코드 저장소 모두 **Kimi K3 License** 아래 배포되며 vLLM·SGLang·TokenSpeed 추론 엔진이 권장된다.
([Hugging Face — moonshotai/Kimi-K3](https://huggingface.co/moonshotai/Kimi-K3))

## 🤖 AI 코딩 에이전트

### Copilot 앱 전용 접근 정책 · 엔터프라이즈 관리 설정 확대 — GitHub (7/27)

GitHub이 **GitHub Copilot 앱에 Copilot CLI와 분리된 전용 접근 정책**을 추가했다. 엔터프라이즈·조직 수준에서 **Enabled everywhere / Disabled everywhere / Let organizations decide** 세 가지로 접근을 제어하며 기본값은 활성이다. 같은 날 **`managed-settings.json` 기반 엔터프라이즈 관리 설정이 Copilot 앱과 Copilot cloud agent까지 확대**되어, 기존에 Copilot CLI·VS Code에만 적용되던 플러그인 허용 목록, 마켓플레이스 제한, 승인 프롬프트 우회 여부를 모든 Copilot 클라이언트에 동일하게 적용할 수 있게 됐다.
([GitHub Changelog — Manage GitHub Copilot app access with a dedicated policy](https://github.blog/changelog/2026-07-27-manage-github-copilot-app-access-with-a-dedicated-policy) · [Enterprise managed settings in the GitHub Copilot app and Copilot cloud agent](https://github.blog/changelog/2026-07-27-enterprise-managed-settings-now-apply-to-the-github-copilot-app))

### JetBrains용 Copilot에 OpenTelemetry 설정 · 모델 관리 추가 — GitHub (7/27)

GitHub이 **JetBrains용 Copilot 플러그인**에 에이전트 워크플로의 **OpenTelemetry 내보내기 설정**(Settings > Tools > GitHub Copilot > Chat)과 **모델 관리 제어**를 추가했다. 커스텀 엔드포인트의 기본 토큰 상한(`maxInputToken`·`maxOutputToken`)을 지정하고 내장 Copilot 모델을 개별로 켜고 끌 수 있다. **Claude 에이전트 플로에서 MCP 서버와 커스텀 에이전트를 직접 사용**하는 기능, Copilot CLI의 fork 지원과 `/rubber-duck` 명령, macOS·Linux의 MCP 진단·경로 처리 개선, 엔터프라이즈 사용자 대상 AI 크레딧 소비량 표시도 함께 들어갔다.
([GitHub Changelog — GitHub Copilot for JetBrains adds improved OpenTelemetry configuration and model management](https://github.blog/changelog/2026-07-27-github-copilot-for-jetbrains-adds-improvved-opentelemetry-configuration-and-model-management))

### Grok 4.5 GitHub Copilot 제공 시작 — GitHub · xAI (7/28)

xAI의 추론 모델 **Grok 4.5**가 GitHub Copilot에 순차 배포되기 시작했다. **최대 50만 토큰 컨텍스트**, 텍스트·이미지 입력, low/medium/high 세 단계 추론 강도를 지원한다. GitHub은 내부 테스트에서 VS Code·Copilot CLI의 터미널 기반 코딩 작업, 특히 **도구를 병렬로 호출하고 직접 실행하는 상황**에서 좋은 결과를 보였다고 밝혔다. Copilot Pro·Pro+·Max·Business·Enterprise에서 쓸 수 있고 제공사 정가 기준 사용량 과금이 적용되며, Business·Enterprise는 관리자가 **기본값이 꺼짐인 Grok 4.5 정책을 켜야** 한다.
([GitHub Changelog — Grok 4.5 is now available in GitHub Copilot](https://github.blog/changelog/2026-07-28-grok-4-5-is-now-available-in-github-copilot))

### Copilot 앱 사용량 지표 사용자 단위로 확대 — GitHub (7/28)

GitHub이 **Copilot 사용량 지표 API**에서 Copilot 앱 활동을 엔터프라이즈 총계로만 보여주던 제한을 풀고 **사용자 단위 데이터**를 제공하기 시작했다. 일자별 Copilot 앱 활성 여부, 사용자별 세션 수·요청 수·프롬프트 수·토큰 사용량이 노출되고, 기능·모델·언어별 롤업과 코드 생성·수락·라인 수 집계에도 Copilot 앱 활동이 포함된다. 기존 응답과 하위 호환이며 Copilot 앱 활동이 없는 항목은 새 필드를 생략한다.
([GitHub Changelog — GitHub Copilot app usage metrics now expand across report rollups](https://github.blog/changelog/2026-07-28-github-copilot-app-usage-metrics-now-expand-across-report-rollups))

## 🛠️ 도구 · 벤치마크

### AgentENV 오픈소스 공개 — Moonshot AI Kimi 팀 · kvcache-ai (7/27)

Kimi K3의 **에이전트 강화학습(RL) 학습을 뒷받침한 분산 실행 플랫폼 'AgentENV(AENV)'**가 **MIT 라이선스**로 공개됐다. 각 에이전트 환경을 컨테이너가 아닌 **Firecracker 마이크로VM**으로 띄워 커널 수준 격리를 확보하고, OCI 이미지를 on-demand로 로드한다. 스냅샷 기반 환경은 **부팅·재개 50ms 미만, 일시정지 100ms 미만**이며 실행 중인 샌드박스를 여러 독립 샌드박스로 **fork**할 수 있다. 메모리 벌루닝으로 높은 오버커밋 비율을 견디고 ublk로 호스트 페이지 캐시를 공유한다. HTTP API가 **E2B 호환**이라 기존 E2B Python·TypeScript SDK 코드를 수정 없이 쓸 수 있다. 요구 사항은 Linux 커널 6.8 이상과 `/dev/kvm` 접근 권한이다.
([GitHub — kvcache-ai/AgentEnv](https://github.com/kvcache-ai/AgentEnv))

### MCP 2026-07-28 사양 공개 — Model Context Protocol · Anthropic (7/28)

MCP의 다섯 번째 사양 **2026-07-28**이 공개됐다. 세션 관리와 핸드셰이크를 없앤 **무상태(stateless) 프로토콜 코어**로 전환해 로드밸런서 뒤 어느 인스턴스로도 요청이 갈 수 있게 했고, 무상태 연결에서 사용자 확인 같은 서버→클라이언트 상호작용을 처리하는 **Multi Round-Trip Requests(`resultType: "input_required"`)**, JSON 본문을 파싱하지 않고 라우팅하는 **`Mcp-Method`·`Mcp-Name` 헤더**, list·read 응답의 **`ttlMs`·`cacheScope` 캐시 파라미터**를 추가했다. 인가는 RFC 9207 issuer 검증과 자격증명-issuer 바인딩을 도입하고 **동적 클라이언트 등록(DCR)을 폐기 예정으로 지정**, Client ID Metadata Documents로 대체한다. Tasks·MCP Apps·Enterprise Managed Authorization은 **정식 확장(extensions) 체계**로 편입됐고 Tier 1 SDK 4종(TypeScript·Python·Go·C#)이 함께 갱신됐다. Anthropic은 같은 날 Claude 제품에 MCP Apps, 엔터프라이즈 관리 인증, 옵저버빌리티 대시보드, **MCP 터널(리서치 프리뷰)** 적용을 발표하며 MCP SDK 월 다운로드 4억 건, Claude 커넥터 디렉터리 등록 서버 950개 이상을 함께 밝혔다.
([MCP Blog — The 2026-07-28 Specification](https://blog.modelcontextprotocol.io/posts/2026-07-28/) · [Claude Blog — Bringing MCP 2026-07-28 to Claude](https://claude.com/blog/bringing-mcp-2026-07-28-to-claude))

### Claude Mythos Preview로 HAWK·AES 공격 개선 발견 — Anthropic (7/28)

Anthropic이 **Claude Mythos Preview**를 이용해 암호 알고리즘 공격 두 건을 개선한 연구를 공개했다. 첫째는 NIST가 검토 중인 양자내성 전자서명 방식 **HAWK**의 격자에서 **비자명 자기동형사상(nontrivial automorphism)**을 찾아, HAWK-256을 깨는 기대 비용을 **2^64에서 2^38로** 낮췄다(연구자와 Claude가 약 60시간 협업, API 비용 약 10만 달러). 둘째는 10라운드 중 **7라운드 AES**에 대해 **'Möbius Bridge'** 기법으로 테이블 조회 성공 수를 늘려 기존 meet-in-the-middle 방식 대비 **200~800배** 빠른 공격을 만든 것으로, 스캐폴드를 통해 Claude가 대부분 자율적으로 발견했다. Anthropic은 두 결과 모두 **현재 운영 시스템에는 영향이 없다**고 명시했다.
([Anthropic Research — Discovering cryptographic weaknesses with Claude](https://www.anthropic.com/research/discovering-cryptographic-weaknesses))

### 에이전트 침입 사고 기술 타임라인 공개 — Hugging Face (7/27)

Hugging Face가 7월 9~13일 자사 인프라에서 발생한 **자율 에이전트 침입 사고의 기술 타임라인**을 공개했다. 복구·분석한 공격자 행위는 **17,600건**이며 약 **6,280개 명령 클러스터**로 묶였다. 데이터셋 프로세서를 노린 **두 개의 인젝션 경로**로 초기 침투가 이뤄졌고, 3일차(7월 11일)에 측면 이동이 급증했다. 사고 과정에서 **시크릿 136개가 담긴 프로덕션 오브젝트 1건**이 읽혔고, 탈취된 VPN 인증으로 **내부 노드 22개**가 보였으며 외부 샌드박스에서 **VPN 등록 시도 181건**이 있었다. 접근된 것은 평가 챌린지 정답이 담긴 **데이터셋 5개**이고, 그 외 고객 대상 모델·데이터셋·Spaces·패키지는 영향을 받지 않았다고 밝혔다.
([Hugging Face Blog — Anatomy of a Frontier Lab Agent Intrusion: A Technical Timeline of the July 2026 Incident](https://huggingface.co/blog/agent-intrusion-technical-timeline))
