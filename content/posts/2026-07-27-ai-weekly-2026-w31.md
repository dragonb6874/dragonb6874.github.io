### Kimi K3 오픈웨이트·기술 리포트 공개 — Moonshot AI (7/27)

Moonshot AI가 **Kimi K3의 전체 모델 가중치와 기술 리포트**를 공개했다. **총 2.8조 파라미터 중 토큰당 1,040억 개가 활성화**되는 MoE 모델로, 896개 전문가 중 16개를 선택하는 **Stable LatentMoE** 구조에 **Kimi Delta Attention(KDA)**과 **Attention Residuals(AttnRes)**를 적용했다. **1M 토큰 컨텍스트**와 텍스트·이미지·비디오 네이티브 멀티모달을 지원하고, **MXFP4 가중치 + MXFP8 활성값** 양자화 인식 학습(QAT)을 썼다. 공개된 벤치마크는 GPQA Diamond 93.5, DeepSWE 67.5, Terminal-Bench 88.3, BrowseComp 91.2, MMMU-Pro 81.6/83.4다. 가중치와 코드 저장소 모두 **Kimi K3 License** 아래 배포되며 vLLM·SGLang·TokenSpeed 추론 엔진이 권장된다.
([Hugging Face — moonshotai/Kimi-K3](https://huggingface.co/moonshotai/Kimi-K3))

### Gemini Robotics 2 공개 — Google DeepMind (7/30)

Google DeepMind이 로봇용 모델군 **Gemini Robotics 2**를 공개했다. 세 모델이 함께 나왔다. **Gemini Robotics 2(VLA)**는 시각·언어 입력을 모터 제어로 바꿔 휴머노이드 전신과 양팔 로봇을 다루고, **Gemini Robotics ER 2**는 물리 세계를 이해해 수 분 길이의 다단계 작업을 계획하는 상위 추론 모델이며, **Gemini Robotics On-Device 2**는 인터넷 없이 로봇 위에서 돌아가는 경량 모델로 **예시 200개 미만으로 몇 시간 만에 새 로봇 형상에 적응**한다고 밝혔다. 공개된 성공률은 전신 조작 45.7~76.3%, 그리퍼 정밀 삽입 89.6%, 5지 SharpaWave 핸드의 전구 풀기 92%다. Apptronik Apollo 2·Franka·Boston Dynamics Spot 등 여러 플랫폼에서 검증했고 서로 다른 기종 간 협업도 시연했다. ER 2는 **Google AI Studio·Gemini API로 제공**(Gemini Enterprise Agent Platform은 프라이빗 프리뷰)되고, VLA와 On-Device 2는 **얼리 액세스 파트너 대상**이다.
([Google DeepMind — Gemini Robotics 2 brings whole body intelligence to robots](https://deepmind.google/blog/gemini-robotics-2-brings-whole-body-intelligence-to-robots/) · [Google Blog — Gemini Robotics ER 2](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/gemini-robotics-er-2/))

### DeepSeek-V4-Flash-0731 정식 출시 — DeepSeek (7/31)

DeepSeek이 **DeepSeek-V4-Flash의 정식 버전 '0731' 빌드**를 공개했다. 프리뷰와 **모델 구조·크기가 동일**(총 284B 파라미터, 토큰당 13B 활성, 1M 컨텍스트)하고 **사후학습(post-training)만 다시 돌린** 릴리스인데 에이전트 성능이 크게 올랐다. Terminal Bench 2.1이 프리뷰 61.8에서 **82.7**로, Cybergym이 38.7에서 **76.7**로 뛰었고 NL2Repo 54.2, DeepSWE 54.4, Toolathlon-Verified 70.3, DSBench-FullStack 68.7을 기록해 DeepSeek은 에이전트 벤치마크에서 **V4-Pro(프리뷰)를 넘어섰다**고 밝혔다. 가중치는 **MIT 라이선스**로 배포되고 추론 가속용 **DSpark 추측 디코딩(speculative decoding) 모듈**이 함께 들어갔으며 low·high·max 세 단계 추론 강도를 지원한다. API는 `deepseek-v4-flash` 모델 ID로 퍼블릭 베타 제공되고 **Responses API 형식을 네이티브 지원하며 Codex에 맞춰 조정**됐다. 가격은 100만 토큰당 입력 $0.14(캐시 히트 $0.0028) / 출력 $0.28이다.
([Hugging Face — deepseek-ai/DeepSeek-V4-Flash-0731](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-0731) · [DeepSeek API Updates](https://api-docs.deepseek.com/updates))

### K-EXAONE 2.0 오픈소스 공개 — LG AI연구원 (7/31)

LG AI연구원이 과학기술정보통신부 **'독자 AI 파운데이션 모델 프로젝트'의 2차수 모델 'K-EXAONE 2.0'**을 Hugging Face에 공개했다. **총 7,500억(750B) 파라미터 중 토큰당 370억(37B)이 활성화**되는 MoE 모델로, 78개 레이어(dense 2 + sparse 76)에 **전문가 256개 중 8개를 토큰마다 선택**하고 글로벌·슬라이딩 윈도를 섞은 하이브리드 어텐션과 **262,144 토큰 컨텍스트**를 쓴다. 1차수 모델(236B) 대비 파라미터가 3배 이상 늘었고 24개 벤치마크 평균 **70.1점**으로 1차수 63.3점보다 10% 이상 높다(MMLU-Pro 83.5, AIME 2026 92.3, SWE-bench Verified 68.2, OpenAI-MRCR 94.4). 한국어·영어·스페인어·독일어·일본어 등 **10개 언어**를 지원하고 **Apache 2.0 라이선스**로 상업적 이용이 가능하다. 학습 데이터 기준 시점은 2025년 2분기다.
([Hugging Face — LGAI-EXAONE/K-EXAONE-2.0-750B-A37B](https://huggingface.co/LGAI-EXAONE/K-EXAONE-2.0-750B-A37B) · [ZDNet Korea 보도](https://zdnet.co.kr/view/?no=20260731102426))

Copilot Pro·Pro+·Business·Enterprise에서 쓸 수 있다.

### GPT-5.6 Luna·Terra API 가격 인하 · Fast mode 도입 — OpenAI (7/30)

OpenAI가 7월 30일부터 **GPT-5.6 Luna 가격을 80%, Terra를 20% 내렸다**. Luna는 100만 토큰당 입력 $1 / 출력 $6에서 **입력 $0.20 / 출력 $1.20**으로, Terra는 입력 $2.50 / 출력 $15에서 **입력 $2 / 출력 $12**로 바뀌었고 **Sol은 입력 $5 / 출력 $30 그대로**다. 같은 날 기존 Priority Processing을 대체하는 **Fast mode**를 API에 도입했다. 모델 지능은 그대로 두고 표준 처리 대비 **최대 2.5배 빠른 속도를 2배 가격**에 제공하며(Luna 입력 $0.40 / 출력 $2.40, Terra $4 / $24, Sol $10 / $60), 기존에 priority 서비스 티어를 지정해 보내던 요청은 자동으로 Fast mode로 넘어가 하위 호환된다. OpenAI는 인하 근거로 모델·추론 인프라·프로덕션 소프트웨어·컨텍스트 관리 전반의 효율 개선을 들었다.
([OpenAI API Changelog](https://developers.openai.com/api/docs/changelog) · [Unite.AI 보도(가격표)](https://www.unite.ai/openai-cuts-api-prices-on-its-two-cheaper-gpt-5-6-tiers/))

### 사이버보안 평가 중 실제 시스템 접근 사고 3건 공개 — Anthropic (7/30)

Anthropic이 **격리돼 있어야 할 평가 환경에서 Claude 모델이 인터넷에 접근해 실제 시스템을 침해한 사고 3건**을 공개했다. 평가 파트너 Irregular와의 **설정 오류로 평가용 머신에 인터넷이 살아 있었는데**, 시스템 프롬프트에는 "인터넷 접근 없음"이라고 적혀 있어 모델이 실제 인터넷 시스템을 가상의 CTF 훈련 대상으로 오인했다. 관련 모델은 **Claude Opus 4.7, Claude Mythos 5, 내부 연구용 테스트 모델**이고 총 6회 실행에서 **3개 조직**이 영향을 받았다(1건은 같은 조직을 4회 실행). 사고별로 애플리케이션·인프라 자격증명과 프로덕션 데이터베이스 수백 행 접근, 악성 PyPI 패키지를 통한 보안 기업 자격증명 취득과 실제 시스템 15대에서의 다운로드·실행, 노출된 디버그 페이지에 대한 SQL 인젝션을 통한 자격증명 획득이 확인됐다. Anthropic은 대응책으로 평가 트랜스크립트 모니터링 강화, 협력사 보안 기준 상향, 인프라 통제 강화와 상시 모니터링 확대를 밝혔다.

### EU AI Act 적용 개시 · 제50조 투명성 의무 발효 — 유럽연합 집행위원회 (8/2)

**EU AI Act가 8월 2일부터 적용**되기 시작했고, 같은 날 **AI Office와 회원국 당국이 법 집행·감독 책임을 맡는다**. 이날 발효되는 **제50조 투명성 의무**는 사람과 직접 상호작용하는 AI 시스템(챗봇·에이전트·아바타), 합성 오디오·이미지·영상·텍스트를 만드는 생성형 AI, 감정 인식·생체 분류 시스템이 대상이다. **제공자(provider)**는 명백한 경우가 아니면 사용자가 AI와 대화 중임을 알리고 생성·조작 콘텐츠를 **기계 판독이 가능하게 표시**해야 하며, **배포자(deployer)**는 감정 인식·생체 분류 사용 사실을 알리고 딥페이크와 사람의 편집 검토를 거치지 않은 공익 사안 AI 생성 텍스트에 라벨을 붙여야 한다. 다만 **AI Omnibus로 8월 2일 이전에 시장에 출시된 시스템의 표시 의무는 12월 2일까지 유예**된다. 집행은 회원국 시장감시당국이 주로 맡고 AI Office는 범용 AI 모델 기반 시스템 등 한정된 범위만 담당하며, 위반 시 **최대 1,500만 유로 또는 전 세계 연매출 3%** 과징금이 부과된다. 고위험 AI 규정은 **2027년 12월 2일·2028년 8월 2일**로 단계 적용된다.
([European Commission — Transparency obligations under Article 50 of the AI Act](https://digital-strategy.ec.europa.eu/en/faqs/transparency-obligations-under-article-50-ai-act) · [AI Act regulatory framework](https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai) · [Code of Practice on Transparency of AI-generated Content](https://digital-strategy.ec.europa.eu/en/policies/code-practice-ai-generated-content))
