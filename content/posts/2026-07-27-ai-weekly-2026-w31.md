## 🧠 모델 출시

### Kimi K3 오픈웨이트·기술 리포트 공개 — Moonshot AI (7/27)

Moonshot AI가 **Kimi K3의 전체 모델 가중치와 기술 리포트**를 공개했다. **총 2.8조 파라미터 중 토큰당 1,040억 개가 활성화**되는 MoE 모델로, 896개 전문가 중 16개를 선택하는 **Stable LatentMoE** 구조에 **Kimi Delta Attention(KDA)**과 **Attention Residuals(AttnRes)**를 적용했다. **1M 토큰 컨텍스트**와 텍스트·이미지·비디오 네이티브 멀티모달을 지원하고, **MXFP4 가중치 + MXFP8 활성값** 양자화 인식 학습(QAT)을 썼다. 공개된 벤치마크는 GPQA Diamond 93.5, DeepSWE 67.5, Terminal-Bench 88.3, BrowseComp 91.2, MMMU-Pro 81.6/83.4다. 가중치와 코드 저장소 모두 **Kimi K3 License** 아래 배포되며 vLLM·SGLang·TokenSpeed 추론 엔진이 권장된다.
([Hugging Face — moonshotai/Kimi-K3](https://huggingface.co/moonshotai/Kimi-K3))

## 🤖 AI 코딩 에이전트

### Copilot 앱 전용 접근 정책 · 엔터프라이즈 관리 설정 확대 — GitHub (7/27)

GitHub이 **GitHub Copilot 앱에 Copilot CLI와 분리된 전용 접근 정책**을 추가했다. 엔터프라이즈·조직 수준에서 **Enabled everywhere / Disabled everywhere / Let organizations decide** 세 가지로 접근을 제어하며 기본값은 활성이다. 같은 날 **`managed-settings.json` 기반 엔터프라이즈 관리 설정이 Copilot 앱과 Copilot cloud agent까지 확대**되어, 기존에 Copilot CLI·VS Code에만 적용되던 플러그인 허용 목록, 마켓플레이스 제한, 승인 프롬프트 우회 여부를 모든 Copilot 클라이언트에 동일하게 적용할 수 있게 됐다.
([GitHub Changelog — Manage GitHub Copilot app access with a dedicated policy](https://github.blog/changelog/2026-07-27-manage-github-copilot-app-access-with-a-dedicated-policy) · [Enterprise managed settings in the GitHub Copilot app and Copilot cloud agent](https://github.blog/changelog/2026-07-27-enterprise-managed-settings-now-apply-to-the-github-copilot-app))

## 🛠️ 도구 · 벤치마크

### AgentENV 오픈소스 공개 — Moonshot AI Kimi 팀 · kvcache-ai (7/27)

Kimi K3의 **에이전트 강화학습(RL) 학습을 뒷받침한 분산 실행 플랫폼 'AgentENV(AENV)'**가 **MIT 라이선스**로 공개됐다. 각 에이전트 환경을 컨테이너가 아닌 **Firecracker 마이크로VM**으로 띄워 커널 수준 격리를 확보하고, OCI 이미지를 on-demand로 로드한다. 스냅샷 기반 환경은 **부팅·재개 50ms 미만, 일시정지 100ms 미만**이며 실행 중인 샌드박스를 여러 독립 샌드박스로 **fork**할 수 있다. 메모리 벌루닝으로 높은 오버커밋 비율을 견디고 ublk로 호스트 페이지 캐시를 공유한다. HTTP API가 **E2B 호환**이라 기존 E2B Python·TypeScript SDK 코드를 수정 없이 쓸 수 있다. 요구 사항은 Linux 커널 6.8 이상과 `/dev/kvm` 접근 권한이다.
([GitHub — kvcache-ai/AgentEnv](https://github.com/kvcache-ai/AgentEnv))
