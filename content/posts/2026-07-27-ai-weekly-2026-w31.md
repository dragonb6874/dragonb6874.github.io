### AgentENV 오픈소스 공개 — Moonshot AI Kimi 팀 · kvcache-ai (7/27)

Kimi K3의 **에이전트 강화학습(RL) 학습을 뒷받침한 분산 실행 플랫폼 'AgentENV(AENV)'**가 **MIT 라이선스**로 공개됐다. 각 에이전트 환경을 컨테이너가 아닌 **Firecracker 마이크로VM**으로 띄워 커널 수준 격리를 확보하고, OCI 이미지를 on-demand로 로드한다. 스냅샷 기반 환경은 **부팅·재개 50ms 미만, 일시정지 100ms 미만**이며 실행 중인 샌드박스를 여러 독립 샌드박스로 **fork**할 수 있다. 메모리 벌루닝으로 높은 오버커밋 비율을 견디고 ublk로 호스트 페이지 캐시를 공유한다. HTTP API가 **E2B 호환**이라 기존 E2B Python·TypeScript SDK 코드를 수정 없이 쓸 수 있다. 요구 사항은 Linux 커널 6.8 이상과 `/dev/kvm` 접근 권한이다.
([GitHub — kvcache-ai/AgentEnv](https://github.com/kvcache-ai/AgentEnv))

### MCP 2026-07-28 사양 공개 — Model Context Protocol · Anthropic (7/28)

MCP의 다섯 번째 사양 **2026-07-28**이 공개됐다. 세션 관리와 핸드셰이크를 없앤 **무상태(stateless) 프로토콜 코어**로 전환해 로드밸런서 뒤 어느 인스턴스로도 요청이 갈 수 있게 했고, 무상태 연결에서 사용자 확인 같은 서버→클라이언트 상호작용을 처리하는 **Multi Round-Trip Requests(`resultType: "input_required"`)**, JSON 본문을 파싱하지 않고 라우팅하는 **`Mcp-Method`·`Mcp-Name` 헤더**, list·read 응답의 **`ttlMs`·`cacheScope` 캐시 파라미터**를 추가했다. 인가는 RFC 9207 issuer 검증과 자격증명-issuer 바인딩을 도입하고 **동적 클라이언트 등록(DCR)을 폐기 예정으로 지정**, Client ID Metadata Documents로 대체한다. Tasks·MCP Apps·Enterprise Managed Authorization은 **정식 확장(extensions) 체계**로 편입됐고 Tier 1 SDK 4종(TypeScript·Python·Go·C#)이 함께 갱신됐다. Anthropic은 같은 날 Claude 제품에 MCP Apps, 엔터프라이즈 관리 인증, 옵저버빌리티 대시보드, **MCP 터널(리서치 프리뷰)** 적용을 발표하며 MCP SDK 월 다운로드 4억 건, Claude 커넥터 디렉터리 등록 서버 950개 이상을 함께 밝혔다.
([MCP Blog — The 2026-07-28 Specification](https://blog.modelcontextprotocol.io/posts/2026-07-28/) · [Claude Blog — Bringing MCP 2026-07-28 to Claude](https://claude.com/blog/bringing-mcp-2026-07-28-to-claude))

### Claude Mythos Preview로 HAWK·AES 공격 개선 발견 — Anthropic (7/28)

Anthropic이 **Claude Mythos Preview**를 이용해 암호 알고리즘 공격 두 건을 개선한 연구를 공개했다. 첫째는 NIST가 검토 중인 양자내성 전자서명 방식 **HAWK**의 격자에서 **비자명 자기동형사상(nontrivial automorphism)**을 찾아, HAWK-256을 깨는 기대 비용을 **2^64에서 2^38로** 낮췄다(연구자와 Claude가 약 60시간 협업, API 비용 약 10만 달러). 둘째는 10라운드 중 **7라운드 AES**에 대해 **'Möbius Bridge'** 기법으로 테이블 조회 성공 수를 늘려 기존 meet-in-the-middle 방식 대비 **200~800배** 빠른 공격을 만든 것으로, 스캐폴드를 통해 Claude가 대부분 자율적으로 발견했다. Anthropic은 두 결과 모두 **현재 운영 시스템에는 영향이 없다**고 명시했다.
([Anthropic Research — Discovering cryptographic weaknesses with Claude](https://www.anthropic.com/research/discovering-cryptographic-weaknesses))

### FY26 Q4 실적 — AI 인프라 capex·Azure 성장 공개 — Microsoft (7/29)

Microsoft가 **2026 회계연도 4분기 실적**을 발표했다. 분기 매출 **900억 달러(+18%)**, Microsoft Cloud **593억 달러(+27%)**, **Azure 및 기타 클라우드 서비스 +43%**이며 상업 부문 잔여 이행 의무는 84% 증가한 **6,780억 달러**다. Satya Nadella는 회계연도 기준 **Azure 매출이 처음 1,000억 달러를 넘었다**고 밝혔고, Microsoft 365 Copilot 유료 시트는 **3,000만 개 이상**으로 집계됐다. 실적에는 **Anthropic 투자 관련 32억 달러 이익**이 개별 항목으로 포함됐다. 유형자산 지출은 분기 **358억 달러**(전년 동기 170.8억 달러의 두 배 이상), 연간 **1,159.5억 달러**(전년 645.5억 달러 대비 약 80% 증가)로, 이 중 약 **3분의 2가 CPU·GPU 등 단기 수명 자산**이다.
