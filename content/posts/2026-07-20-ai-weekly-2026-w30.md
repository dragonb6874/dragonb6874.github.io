Google이 **Gemini 3.6 Flash**, **3.5 Flash-Lite**, **3.5 Flash Cyber**(보안 특화, 제한 파일럿)를 발표했다. 주력 모델인 **3.6 Flash**는 Artificial Analysis Index 기준 3.5 Flash 대비 **출력 토큰 사용량 17% 감소**(DeepSWE 벤치마크 등에서는 최대 65% 감소), 코딩 성능 향상(DeepSWE 37%→49%), 지식 컷오프 2025년 1월→2026년 3월로 갱신됐다. 가격은 100만 토큰당 **입력 $1.50 / 출력 $7.50**, **3.5 Flash-Lite**는 입력 $0.30 / 출력 $2.50. 3.6 Flash·Flash-Lite는 Gemini API(AI Studio·Android Studio)에서 즉시 제공되며 3.6 Flash는 Google Antigravity에도 포함됐다. ([Google — Introducing Gemini 3.6 Flash, 3.5 Flash-Lite, and 3.5 Flash Cyber](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-6-flash-3-5-flash-lite-3-5-flash-cyber/))

## 🤖 AI 코딩 에이전트

### Claude Code 2.1.216 업데이트 — Anthropic (7/20)

Claude Code **2.1.216**이 대형 안정성·보안·성능 릴리스로 출시됐다. 네트워크 egress 제어는 유지하면서 파일시스템 격리만 우회하는 **`sandbox.filesystem.disabled` 설정**을 추가했고, 장시간 세션에서 메시지 정규화가 대화 턴 수에 대해 **2차(quadratic) 복잡도로 느려지던 성능 저하**를 수정했다. 보안 면에서는 워크플로·예약 작업 쓰기에서의 **심볼릭 링크 추종(symlink following) 취약점**, OAuth 토큰 만료·회전 후 auto 모드가 명령을 잘못 거부하던 문제, worktree 격리 서브에이전트가 git 플래그로 공유 체크아웃에 접근하던 문제 등을 고쳤다. 백그라운드 세션 복원, 데몬 lockfile, MCP 재인증, 다수 UI(@-멘션 첨부·vim dot-repeat·resume 피커) 관련 수정도 포함됐다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Claude Code 2.1.217 업데이트 — Anthropic (7/21)

Claude Code **2.1.217**은 잘린 MCP 도구 출력이 잘리지 않은 원본 결과를 계속 붙들고 있던 **메모리 누수**를 고쳤고, 백그라운드 세션 격리에서 심볼릭 링크 디렉터리를 정규화(canonicalization)하도록 개선했다. Bedrock에서 Claude Opus 4.8 사용 시 **auto-compact가 동작**하도록 했고, Claude Desktop 세션에서 기업용 **mTLS·TLS 검증 설정을 준수**하도록 수정했다. 이모지 shortcode 자동완성(`:heart:` → ❤️), transcript 쓰기 실패·세션 저장 비활성 시 경고 표시, Windows 자동 업데이트 실패 시 실행 파일 자동 복구도 포함됐다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Claude Code 2.1.218 업데이트 — Anthropic (7/22)

Claude Code **2.1.218**에서 **`/code-review`가 백그라운드 서브에이전트로 동작**하도록 바뀌어 리뷰 작업이 대화 컨텍스트를 채우지 않는다. `/ultrareview`는 "review my auth changes" 같은 **서술형 인자**를 받을 수 있게 확장됐다. 버그 수정으로는 `\u` 접두 세그먼트가 포함된 Windows 경로가 CJK 문자로 깨지던 문제, 왼쪽 화살표 키가 확인 없이 대화를 버리던 문제, 특정 터미널 설정에서 여러 줄 붙여넣기가 한 줄로 합쳐지던 문제가 포함됐다. `claude mcp list`·`/mcp`에 서버 연결 실패 시 **HTTP 상태 정보**가 추가됐고, 접근성 모드에 삭제된 텍스트의 스크린리더 안내가 들어갔다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Claude Code 2.1.219 업데이트 — Anthropic (7/24)

Claude Code **2.1.219**가 **Claude Opus 5(`claude-opus-5`)를 기본 Opus 모델로 추가**했다(1M 컨텍스트, fast mode 100만 토큰당 $10/$50). `/fast`는 Opus 5·Opus 4.8에만 적용되고 **Opus 4.7은 fast mode에서 제외**됐다. 서브에이전트가 **중첩 서브에이전트를 기본 depth 3까지 생성**할 수 있게 됐고(`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1`로 비활성화), dynamic workflow 기본 크기는 **medium(에이전트 15개 미만 목표)**으로 바뀌었으며 `workflowSizeGuideline` 설정 키가 추가됐다. 샌드박스 명령에서 허용 목록 외 호스트를 프롬프트 없이 거부하는 **`sandbox.network.strictAllowlist`**, `/add-dir` 등으로 작업 디렉터리가 세션 중간에 등록될 때 발동하는 **`DirectoryAdded` 훅**, headless stream-json init 이벤트의 `mcp_server_errors` 필드도 새로 들어갔다. `claude-api` 스킬 기본값도 Opus 5로 갱신됐다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))
