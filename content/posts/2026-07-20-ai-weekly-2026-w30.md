## 🧠 모델 출시

### Fable 5 Max·Team Premium 영구 포함(주간 한도 50%), Pro는 크레딧 전환 — Anthropic (7/20)

7/19까지 이어진 보너스 사용 기간이 끝나면서 **7월 20일부로 Fable 5 접근 정책이 플랜별로 분기**됐다. **Max·Team Premium**은 Fable 5를 **주간 한도의 최대 50%까지 영구 포함**(정규 한도 대비 33% 축소)한다. **Pro·Team Standard**는 포함에서 제외되어 **일회성 $100 사용 크레딧**을 받은 뒤, 소진 시 API 가격(100만 토큰당 입력 $10 / 출력 $50)으로 과금된다. Anthropic은 "Fable demand has been hard to manage and frustrating for users"라며 수요 관리 어려움을 배경으로 들었다.
([The Decoder — Anthropic slashes Claude Fable 5 limits in Max and Team Premium](https://the-decoder.com/anthropic-slashes-claude-fable-5-limits-in-max-and-team-premium-and-pushes-pro-users-toward-api-pricing/))

### Gemini 3.6 Flash · 3.5 Flash-Lite · 3.5 Flash Cyber 출시 — Google (7/21)

Google이 **Gemini 3.6 Flash**, **3.5 Flash-Lite**, **3.5 Flash Cyber**(보안 특화, 제한 파일럿)를 발표했다. 주력 모델인 **3.6 Flash**는 Artificial Analysis Index 기준 3.5 Flash 대비 **출력 토큰 사용량 17% 감소**(DeepSWE 벤치마크 등에서는 최대 65% 감소), 코딩 성능 향상(DeepSWE 37%→49%), 지식 컷오프 2025년 1월→2026년 3월로 갱신됐다. 가격은 100만 토큰당 **입력 $1.50 / 출력 $7.50**, **3.5 Flash-Lite**는 입력 $0.30 / 출력 $2.50. 3.6 Flash·Flash-Lite는 Gemini API(AI Studio·Android Studio)에서 즉시 제공되며 3.6 Flash는 Google Antigravity에도 포함됐다. DeepMind는 **Gemini 4 사전학습을 이미 시작**했다고 밝혔다.
([Google — Introducing Gemini 3.6 Flash, 3.5 Flash-Lite, and 3.5 Flash Cyber](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-6-flash-3-5-flash-lite-3-5-flash-cyber/))

## 🤖 AI 코딩 에이전트

### Claude Code 2.1.216 업데이트 — Anthropic (7/20)

Claude Code **2.1.216**이 대형 안정성·보안·성능 릴리스로 출시됐다. 네트워크 egress 제어는 유지하면서 파일시스템 격리만 우회하는 **`sandbox.filesystem.disabled` 설정**을 추가했고, 장시간 세션에서 메시지 정규화가 대화 턴 수에 대해 **2차(quadratic) 복잡도로 느려지던 성능 저하**를 수정했다. 보안 면에서는 워크플로·예약 작업 쓰기에서의 **심볼릭 링크 추종(symlink following) 취약점**, OAuth 토큰 만료·회전 후 auto 모드가 명령을 잘못 거부하던 문제, worktree 격리 서브에이전트가 git 플래그로 공유 체크아웃에 접근하던 문제 등을 고쳤다. 백그라운드 세션 복원, 데몬 lockfile, MCP 재인증, 다수 UI(@-멘션 첨부·vim dot-repeat·resume 피커) 관련 수정도 포함됐다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### 전량 중국산 칩 1GW 데이터센터 부분 가동 — Z.AI (7/20)

Zhipu에서 사명을 바꾼 **Z.AI**가 **엔비디아를 배제하고 전량 중국산 칩만으로 구성한 대형 데이터센터** 건설을 마치고 부분 가동을 시작했다고 Bloomberg가 보도했다. 자사 GLM 플랫폼의 차세대 모델 학습을 위한 **1기가와트(약 75만 가구 전력 규모)** 허브로, 미국의 대중국 칩 수출 규제 속에서 엔비디아 실리콘을 국산으로 대체하려는 베이징의 노력에서 중요한 진전으로 평가된다. Z.AI는 이미 각각 1만 개 이상 칩을 갖춘 여러 컴퓨팅 클러스터를 구축·운영 중이다.
([Bloomberg — Z.AI Completes Giant Data Center With Chinese Chips to Train AI](https://www.bloomberg.com/news/articles/2026-07-20/z-ai-completes-giant-data-center-with-chinese-chips-to-train-ai))
