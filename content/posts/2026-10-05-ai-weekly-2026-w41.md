### Mistral Large 4 퍼블릭 프리뷰, 1조 파라미터·활성 52B 멀티모달 MoE — Mistral (10/6)

### Claude Haiku 5.5 출시, Haiku 4.5보다 약 75% 저렴·effort 조절 지원 — Anthropic (10/7)

### Cursor iOS 앱에서 로컬 에이전트 원격 제어 — Cursor (10/6)
Cursor가 **데스크톱에서 실행 중인 로컬 에이전트를 iOS 앱에서 보고 답장하는 Remote Control** 기능을 추가했다. iOS 앱에 로그인하면 계정의 컴퓨터가 자동으로 표시되고 데스크톱에서 페어링 요청을 승인하면 연결되며, 에이전트는 계속 로컬 컴퓨터에서 실행되므로(클라우드 에이전트 불필요) 컴퓨터가 켜져 있어야 한다. 자리를 비운 동안 컴퓨터를 깨어 있게 하는 설정이 추가됐고, Enterprise 조직을 제외하고 기본 활성화된다.
출처: [Cursor Changelog — Remote Control for Local Agents](https://cursor.com/changelog/remote-control-local-agents)

### ChatGPT·Codex 텍스트 워터마크 'textGrain', EU 사용자 적용·API는 전 세계 옵트인 — OpenAI (10/5)
OpenAI가 EU AI법 투명성 의무에 맞춰 모델의 단어 선택을 미세하게 조정해 눈에 보이지 않는 패턴을 남기는 텍스트 워터마크 **textGrain**을 공개했다. 수 주에 걸쳐 **EU의 ChatGPT·Codex 텍스트 출력에 전 요금제 적용**되고, API 개발자는 전 세계에서 옵트인으로 쓸 수 있으며, 검출기는 초기에는 승인된 연구자·전문 기관에만 제공된다. OpenAI는 워터마크가 사용자를 식별하지 않고 복사·붙여넣기에도 유지되지만 단어의 10%를 바꾸면 검출률이 92%에서 66%로 떨어진다고 밝혔다.
출처: [OpenAI — EU text provenance](https://openai.com/index/eu-text-provenance/) · [TechCrunch — OpenAI will start watermarking ChatGPT's text in the EU](https://techcrunch.com/2026/10/05/openai-will-start-watermarking-chatgpts-text-in-the-eu/)

### Claude for Google Workspace 퍼블릭 베타, Docs·Sheets·Slides 사이드바에서 직접 편집 — Anthropic (10/6)
Anthropic이 Google Docs·Sheets·Slides 안에 Claude 사이드바를 여는 **Claude for Google Workspace** 애드온을 모든 유료 플랜(Pro·Max·Team·Enterprise)에 퍼블릭 베타로 내놨다. Google Workspace Marketplace에서 설치하면 열린 파일과 선택 영역을 읽고 직접 수정하며, 기본값인 **ask-before-editing 모드**는 변경마다 승인 카드를 띄우고 'Accept all edits'로 바꿀 수 있다. Sheets에서는 수식·피벗 테이블·네이티브 차트 작성과 Python으로 범위를 가져와 정리한 뒤 되쓰기가 가능하고, 채팅에서 Google 파일을 만들고 고치는 Docs·Sheets·Slides **커넥터**(베타)도 함께 나왔다.
출처: [Claude — Claude now works in Google Docs, Sheets, and Slides](https://claude.com/resources/articles/claude-now-works-in-google-docs-sheets-and-slides) · [Claude Help Center — Use Claude in Google Docs, Sheets, and Slides](https://support.claude.com/en/articles/16951679-use-claude-in-google-docs-sheets-and-slides)

### Cyber Verification Program 확대, Project Glasswing 통합·3단계 접근 등급 — Anthropic (10/6)
Anthropic이 검증된 보안 전문가에게 고급 사이버 역량과 완화된 차단 분류기를 제공하는 **Cyber Verification Program**을 확대하고 기존 **Project Glasswing**을 여기에 통합했다. 사고 대응·악성코드 분석용 **Defense Access**, 승인된 침투 테스트·레드팀용 **Red Team Access**(사내·정부·전문 테스트 업체 한정), 항공·전력망 같은 안전 필수 시스템 테스트용 **Specialized Access**(미 정부와 공동 심사) 3단계다. 회사는 Glasswing 파트너가 4~7월에 **12만 9,000건 이상**의 검증된 취약점을 찾았고 이 중 3만 3,000건 이상이 치명·높음 등급이라고 밝혔다.
출처: [Anthropic — Expanding the Cyber Verification Program](https://www.anthropic.com/news/cyber-verification-program)

### Decisions API 퍼블릭 베타, gpt-6-luna로 분류·라우팅·채점을 Responses API보다 약 10배 빠르게 — OpenAI (10/6)
OpenAI가 텍스트·이미지를 받아 **확률(predicate)·선택지(choice)·점수(score)** 형태의 타입 지정된 답을 돌려주는 전용 엔드포인트 `POST /v1/decisions`를 모든 개발자에게 퍼블릭 베타로 열었다. 현재 **gpt-6-luna**만 지원하며 Responses API 대비 약 10배 빠르다고 밝혔고, 가격은 **입력 100만 토큰당 $0.10**에 출력·캐시 과금은 없다. Zero Data Retention·HIPAA·미국/유럽 데이터 레지던시를 지원하고 정식 출시는 "수 주 내"로 예고했다.
출처: [OpenAI Developers — Decisions guide](https://developers.openai.com/api/docs/guides/decisions) · [MIXED — OpenAI's Decisions API runs on gpt-6-luna alone](https://mixed-news.com/en/openai-decisions-api-beta-gpt-6-luna-endpoint-table/)
