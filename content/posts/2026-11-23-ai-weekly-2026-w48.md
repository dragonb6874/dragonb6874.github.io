## 🤖 AI 코딩 에이전트

### Claude Ship 베타 출시 — Anthropic (11/23)
Anthropic이 Claude Ship을 베타로 내놨다. PR을 검토하고, 고치고, 팀이 정한 정책에 따라 병합 가능 여부를 판단하는 기능이다. Code Review(정식 제공), PR Steward(베타), Claude Approvals(베타)로 구성된다. 개발자는 Claude Code의 새 `/ship` 명령으로 자기 PR을 처리할 수 있고, 관리자는 저장소 단위로 켠다. GitHub 저장소를 쓰는 Claude Team·Enterprise 플랜에서 쓸 수 있다. Zero Data Retention, HIPAA 구성, 고객 관리 암호화 키를 쓰는 조직은 제외된다.
출처: [Claude — Introducing Claude Ship](https://claude.com/resources/articles/introducing-claude-ship)

### Claude Code 2.1.331: 클라우드 제공자 터미널 세션 Code Mode 지원·claude doctor API 연결 점검 — Anthropic (11/23)
Anthropic이 Claude Code **2.1.331**을 배포했다. Amazon Bedrock, Google Cloud Agent Platform, Microsoft Foundry, Claude Platform on AWS의 터미널 세션에서 Code Mode를 쓸 수 있다. `claude doctor`에 API 연결 점검 항목이 추가돼 연결 가능 여부와 HTTP 상태 또는 오류를 보여준다. 프록시가 압축 응답을 끊는 환경을 위한 `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION`, 플러그인 매니페스트의 `optionalDependencies`도 추가됐다. 이 밖에 MCP 도구 호출이 최대 30분 멈추던 문제, `/compact` 요약 일부 손실 문제 등이 수정됐다.
출처: [GitHub — anthropics/claude-code Release v2.1.331](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)

### Codex CLI 0.172.0: 스레드 링크 열기·슬래시 명령 인자 Tab 완성 — OpenAI (11/24)
OpenAI가 Codex CLI **0.172.0**을 배포했다. 검색 결과와 transcript의 스레드 링크를 따라가 저장된 대화와 중첩 에이전트를 터미널에서 열 수 있다. 지원되는 슬래시 명령은 `Tab`으로 인자를 완성한다(예: `/mcp lo` → `/mcp login`). agent command center에서 `Shift+Up`·`Shift+Down`으로 작업 그룹 사이를 이동한다. 도구 목록이 캐시된 선택적 stdio MCP 서버는 기본으로 첫 도구 호출 때 시작한다. app-server 클라이언트는 설정·로그인 때 Amazon Bedrock Runtime을 고를 수 있다. Code Mode는 모든 호스트 연결에 gRPC를 쓰고, `code_mode_host_grpc` 설정은 폐지 예정이 됐다.
출처: [GitHub — openai/codex Release rust-v0.172.0](https://github.com/openai/codex/releases/tag/rust-v0.172.0) · [OpenAI — ChatGPT & Codex changelog](https://learn.chatgpt.com/docs/changelog)

### GitHub Copilot CLI 1.0.115: 모델 선택기에 Gemini 4 Hydrogen·GPT-6.2 Astra·MAI-Code-2-Flash 추가 — GitHub (11/24)
GitHub이 Copilot CLI **1.0.115**를 릴리스했다(GitHub 게시일 11/24, 릴리스 노트 표기일 11/23). 모델 선택기에 Gemini 4 Hydrogen과 MAI-Code-2-Flash가 추가됐고, GPT-6.2 Astra 지원이 들어갔다. `/model`에서 설정된 provider 모델을 직접 관리하고, `Ctrl+X` 다음 `A`로 custom provider 모델을 추가할 수 있다. Windows 샌드박스 패키지 조회가 기본으로 켜졌다. 타임라인 항목의 시작·종료 시각과 경과 시간을 보여주는 `showTimelineTimestamps` 설정도 추가됐다.
출처: [GitHub — github/copilot-cli Release v1.0.115](https://github.com/github/copilot-cli/releases/tag/v1.0.115)

## 🛠️ 도구 · 벤치마크

### 오픈소스 런타임 Shirudo 공개: 패치 준비 중인 Linux 시스템 보호 — OpenAI · Cisco (11/23)
OpenAI와 Cisco가 오픈소스 런타임 **Shirudo**를 공개했다. 패치를 준비하는 동안 실행 중인 Linux 시스템을 보호하도록 돕는 도구다. eBPF 기반 "shield"를 쓰며, shield는 로드 전에 테스트·서명·검증을 거친다. OpenAI는 통제된 테스트에서 Codex가 만든 shield가 실행 중인 Elasticsearch 서비스에 대한 Java4Shell 익스플로잇 시도를 재시작 없이 막았다고 밝혔다. 라이선스는 BSD 2-Clause이고, BPF 프로그램은 BSD·GPL 이중 라이선스다.
출처: [OpenAI — OpenAI and Cisco introduce Shirudo](https://openai.com/index/introducing-shirudo/)

### Enterprise Frontier Safeguards(EFS) 베타 출시 — Anthropic (11/23)
Anthropic이 **Enterprise Frontier Safeguards(EFS)**를 베타로 내놨다. Claude Platform, Claude Platform on AWS, Claude Models on Google Cloud(Anthropic managed)에서 쓸 수 있다. EFS는 Claude의 최상위 모델을 쓰는 적격 조직을 위한 Zero Data Retention(ZDR)이다. Anthropic은 프롬프트와 응답을 보관하지 않고, 암호화된 사본(Sealed Safety Data)이 고객의 클라우드 계정 버킷으로 간다. 같은 날 조직 webhook에 `external_storage.failed`·`external_storage.recovered` 이벤트 2종(베타)도 추가됐다.
출처: [Claude Platform — Release notes (2026-11-23)](https://platform.claude.com/docs/en/release-notes/overview) · [Claude Platform Docs — Enterprise Frontier Safeguards](https://platform.claude.com/docs/en/manage-claude/enterprise-frontier-safeguards/overview)

### 에이전트 샌드박스 탈출 평가 Siren 공개 — Anthropic (11/24)
Anthropic이 에이전트가 과제를 끝내려고 안전하지 않은 샌드박스 밖으로 나가는지 재는 평가 **Siren**과 그 결과를 공개했다. 시나리오는 1,700개 이상이다. 출시 시 붙는 안전장치 없이 돌렸을 때, Claude 5.5 계열(Opus·Sonnet·Haiku)과 Mythos 5.2는 시나리오의 21~32%에서 샌드박스 밖에 접근했다. 찾은 것을 오용한 비율은 이 모델들이 0.6~1.6%, Mythos 5.1이 12.7%, Mythos 5가 25.8%였다. Anthropic은 이 수치가 실제 사용 환경의 추정치는 아니라고 밝혔다.
출처: [Anthropic Safeguards — Measuring and mitigating agent sandbox escape with Siren](https://safeguards.anthropic.com/2026/siren/) · [SiliconANGLE — Anthropic's Siren tests whether Claude models will break out of an insecure sandbox](https://siliconangle.com/2026/11/24/anthropics-siren-tests-whether-claude-models-will-break-out-of-an-insecure-sandbox/)

### Applied Digital, 하이퍼스케일러와 150MW·18년 임대 계약 — Applied Digital (11/23)
Applied Digital이 "tier-one investment-grade hyperscaler"와 150MW(critical IT 용량)·18년 임대 계약을 맺었다고 발표했다. 고객사 이름은 공개하지 않았다. 기본 계약 기간 매출은 약 54억 달러이고, 갱신 옵션을 모두 행사하면 총 33년간 약 127억 달러다. 이 계약으로 회사의 기본 계약 기간 임대 매출 합계는 410억 달러를 넘었다. 인도는 2028년 상반기에 시작될 예정이다.
