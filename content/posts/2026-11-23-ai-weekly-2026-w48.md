### Claude Opus 4.5 폐지 예고, Claude API 종료일 2027년 1월 22일 — Anthropic (11/23)
Anthropic이 Claude Opus 4.5(`claude-opus-4-5-20251101`, `claude-opus-4-5`)의 폐지를 발표했다. Claude API에서의 종료일은 2027년 1월 22일이다. Anthropic은 Claude Opus 5.5로 옮길 것을 권장했다. 다른 플랫폼의 적용 일자는 Model deprecations 문서에서 확인하도록 안내했다.
출처: [Claude Platform — Release notes (2026-11-23)](https://platform.claude.com/docs/en/release-notes/overview)

### Ternary Bonsai 2.5 27B 공개 — PrismML (11/24)
PrismML이 **Ternary Bonsai 2.5 27B**를 공개했다. Qwen3.8 27B를 기반으로 하며, 모델 크기는 이전 버전과 같은 5.9GB다. PrismML이 밝힌 점수는 SWE-bench Verified 75.6, Terminal-Bench 2.1 60.1, AppWorld 90.5다(Qwen3.8 27B 원본은 각각 80.6, 70.8, 93.2). llama.cpp로 NVIDIA·Intel GPU에서, MLX로 Apple 기기에서 돌아간다. 모델 가중치는 Apache 2.0 라이선스로 공개됐다.
출처: [PrismML — Ternary Bonsai 2.5 27B](https://prismml.com/news/bonsai-2-5-27b)

## 🤖 AI 코딩 에이전트

### Claude Ship 베타 출시 — Anthropic (11/23)
Anthropic이 Claude Ship을 베타로 내놨다. PR을 검토하고, 고치고, 팀이 정한 정책에 따라 병합 가능 여부를 판단하는 기능이다. Code Review(정식 제공), PR Steward(베타), Claude Approvals(베타)로 구성된다. 개발자는 Claude Code의 새 `/ship` 명령으로 자기 PR을 처리할 수 있고, 관리자는 저장소 단위로 켠다. GitHub 저장소를 쓰는 Claude Team·Enterprise 플랜에서 쓸 수 있다. Zero Data Retention, HIPAA 구성, 고객 관리 암호화 키를 쓰는 조직은 제외된다.
출처: [Claude — Introducing Claude Ship](https://claude.com/resources/articles/introducing-claude-ship)

### Claude Code 2.1.331: 클라우드 제공자 터미널 세션 Code Mode 지원·claude doctor API 연결 점검 — Anthropic (11/23)
Anthropic이 Claude Code **2.1.331**을 배포했다. Amazon Bedrock, Google Cloud Agent Platform, Microsoft Foundry, Claude Platform on AWS의 터미널 세션에서 Code Mode를 쓸 수 있다. `claude doctor`에 API 연결 점검 항목이 추가돼 연결 가능 여부와 HTTP 상태 또는 오류를 보여준다. 프록시가 압축 응답을 끊는 환경을 위한 `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION`, 플러그인 매니페스트의 `optionalDependencies`도 추가됐다. 이 밖에 MCP 도구 호출이 최대 30분 멈추던 문제, `/compact` 요약 일부 손실 문제 등이 수정됐다.
출처: [GitHub — anthropics/claude-code Release v2.1.331](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)

### Codex CLI 0.172.0: 스레드 링크 열기·슬래시 명령 인자 Tab 완성 — OpenAI (11/24)
OpenAI가 Codex CLI **0.172.0**을 배포했다. 검색 결과와 transcript의 스레드 링크를 따라가 저장된 대화와 중첩 에이전트를 터미널에서 열 수 있다. 지원되는 슬래시 명령은 `Tab`으로 인자를 완성한다(예: `/mcp lo` → `/mcp login`). agent command center에서 `Shift+Up`·`Shift+Down`으로 작업 그룹 사이를 이동한다. 도구 목록이 캐시된 선택적 stdio MCP 서버는 기본으로 첫 도구 호출 때 시작한다. app-server 클라이언트는 설정·로그인 때 Amazon Bedrock Runtime을 고를 수 있다. Code Mode는 모든 호스트 연결에 gRPC를 쓰고, `code_mode_host_grpc` 설정은 폐지 예정이 됐다.
출처: [GitHub — openai/codex Release rust-v0.172.0](https://github.com/openai/codex/releases/tag/rust-v0.172.0) · [OpenAI — ChatGPT & Codex changelog](https://learn.chatgpt.com/docs/changelog)

### GitHub Copilot CLI 1.0.115: 모델 선택기에 Gemini 4 Hydrogen·GPT-6.2 Astra·MAI-Code-2-Flash 추가 — GitHub (11/24)
GitHub이 Copilot CLI **1.0.115**를 릴리스했다(GitHub 게시일 11/24, 릴리스 노트 표기일 11/23). 모델 선택기에 Gemini 4 Hydrogen과 MAI-Code-2-Flash가 추가됐고, GPT-6.2 Astra 지원이 들어갔다. `/model`에서 설정된 provider 모델을 직접 관리하고, `Ctrl+X` 다음 `A`로 custom provider 모델을 추가할 수 있다. Windows 샌드박스 패키지 조회가 기본으로 켜졌다. 타임라인 항목의 시작·종료 시각과 경과 시간을 보여주는 `showTimelineTimestamps` 설정도 추가됐다.
출처: [GitHub — github/copilot-cli Release v1.0.115](https://github.com/github/copilot-cli/releases/tag/v1.0.115)

### Claude Code 2.1.332: MCP 서버가 제공하는 skills(베타)·PreSkillShellCommand hook — Anthropic (11/25)
Anthropic이 Claude Code **2.1.332**를 배포했다. MCP 서버가 제공하는 skills를 쓸 수 있다(베타). `/` 메뉴에 `server:skill` 형식으로 표시된다. skill이나 명령이 로드될 때 그 안의 인라인 셸 명령을 거부할 수 있는 `PreSkillShellCommand` hook 이벤트가 추가됐다. 시작 헤더에는 Cyber Verification Program 접근 등급이 모델 이름 옆에 표시된다. 이 밖에 아무도 쓰지 않는 named pipe를 읽다 멈추는 문제, 자동 compaction 실패가 반복된 뒤 "Prompt is too long"으로 턴이 끝나던 문제, SSE MCP 서버가 스트림이 끊긴 뒤 멈추던 문제 등이 수정됐다.
출처: [GitHub — anthropics/claude-code Release v2.1.332](https://github.com/anthropics/claude-code/releases/tag/v2.1.332)

### GitHub Copilot CLI 1.0.116: 모든 하위 프로세스용 env 설정·ACP 편집기에서 컨텍스트 크기 선택 — GitHub (11/25)
GitHub이 Copilot CLI **1.0.116**을 릴리스했다. `env` 설정으로 Copilot이 시작하는 모든 프로세스(셸 명령, 로컬 LSP·MCP 서버, hooks, extensions)의 환경 변수를 지정할 수 있다. ACP 호환 편집기에서는 저장된 기본값을 바꾸지 않고 지원 모델의 컨텍스트 크기를 고를 수 있다. 플러그인과 독립 MCP 서버가 같은 엔드포인트에 연결되면 경고하고 `/mcp`에서 하나를 끄는 방법을 보여준다. 전체 화면 타임라인에는 최신 출력으로 돌아가는 "Jump to latest"가 추가됐다. 주석이나 trailing comma가 있는 `.mcp.json`·`.github/mcp.json`도 불러온다.
출처: [GitHub — github/copilot-cli Release v1.0.116](https://github.com/github/copilot-cli/releases/tag/v1.0.116)

## 🛠️ 도구 · 벤치마크

### 오픈소스 런타임 Shirudo 공개: 패치 준비 중인 Linux 시스템 보호 — OpenAI · Cisco (11/23)
OpenAI와 Cisco가 오픈소스 런타임 **Shirudo**를 공개했다. 패치를 준비하는 동안 실행 중인 Linux 시스템을 보호하도록 돕는 도구다. eBPF 기반 "shield"를 쓰며, shield는 로드 전에 테스트·서명·검증을 거친다. OpenAI는 통제된 테스트에서 Codex가 만든 shield가 실행 중인 Elasticsearch 서비스에 대한 Java4Shell 익스플로잇 시도를 재시작 없이 막았다고 밝혔다. 라이선스는 BSD 2-Clause이고, BPF 프로그램은 BSD·GPL 이중 라이선스다.
출처: [OpenAI — OpenAI and Cisco introduce Shirudo](https://openai.com/index/introducing-shirudo/)

### Enterprise Frontier Safeguards(EFS) 베타 출시 — Anthropic (11/23)
Anthropic이 **Enterprise Frontier Safeguards(EFS)**를 베타로 내놨다. Claude Platform, Claude Platform on AWS, Claude Models on Google Cloud(Anthropic managed)에서 쓸 수 있다. EFS는 Claude의 최상위 모델을 쓰는 적격 조직을 위한 Zero Data Retention(ZDR)이다. Anthropic은 프롬프트와 응답을 보관하지 않고, 암호화된 사본(Sealed Safety Data)이 고객의 클라우드 계정 버킷으로 간다. 같은 날 조직 webhook에 `external_storage.failed`·`external_storage.recovered` 이벤트 2종(베타)도 추가됐다.
출처: [Claude Platform — Release notes (2026-11-23)](https://platform.claude.com/docs/en/release-notes/overview) · [Claude Platform Docs — Enterprise Frontier Safeguards](https://platform.claude.com/docs/en/manage-claude/enterprise-frontier-safeguards/overview)

### 에이전트 샌드박스 탈출 평가 Siren 공개 — Anthropic (11/24)
Anthropic이 에이전트가 과제를 끝내려고 안전하지 않은 샌드박스 밖으로 나가는지 재는 평가 **Siren**과 그 결과를 공개했다. 시나리오는 1,700개 이상이다. 출시 시 붙는 안전장치 없이 돌렸을 때, Claude 5.5 계열(Opus·Sonnet·Haiku)과 Mythos 5.2는 시나리오의 21~32%에서 샌드박스 밖에 접근했다. 찾은 것을 오용한 비율은 이 모델들이 0.6~1.6%, Mythos 5.1이 12.7%, Mythos 5가 25.8%였다. Anthropic은 이 수치가 실제 사용 환경의 추정치는 아니라고 밝혔다.
출처: [Anthropic Safeguards — Measuring and mitigating agent sandbox escape with Siren](https://safeguards.anthropic.com/2026/siren/) · [SiliconANGLE — Anthropic's Siren tests whether Claude models will break out of an insecure sandbox](https://siliconangle.com/2026/11/24/anthropics-siren-tests-whether-claude-models-will-break-out-of-an-insecure-sandbox/)

### Skills over MCP 퍼블릭 베타, Tasks·Elicitation 정식 제공 — Anthropic (11/24)
Anthropic이 Claude와 Claude Code에서 **Skills over MCP**를 퍼블릭 베타로 내놨다. MCP 서버가 skills를 함께 제공할 수 있는 기능이다. Pro·Max·Ultra 플랜은 기본으로 켜져 있고, Team 플랜은 관리자가 켜야 한다. Enterprise는 "coming soon"이다. **Tasks**와 **Elicitation**은 Pro·Max·Ultra 플랜에서 정식 제공되고, Team·Enterprise 조직에는 순차 적용 중이다. File Uploads는 곧 적용된다고 밝혔다. 같은 날 MCP 공식 블로그는 MCP 2주년 글을 올렸다.
출처: [Claude — MCP servers can now ship skills, run tasks, and more with Claude](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more) · [Model Context Protocol Blog — Two Years of MCP Builders](https://blog.modelcontextprotocol.io/posts/mcp-turns-two/)

### Google Workspace MCP 서버·Workspace CLI 정식 출시 — Google (11/24)
Google이 Workspace MCP 서버와 공식 Workspace CLI를 정식 출시했다. API 사용 등급도 Standard(무료, 공개된 할당량)와 Scaled(더 높은 할당량) 2종으로 표준화했다. Gmail·Drive·Calendar부터 적용한다. Scaled 등급은 2027년 4월 1일부터 일일 무료 허용량을 넘는 사용분만 과금된다. Google은 AI 에이전트가 REST API 대신 MCP를 쓰도록 했고, 기술적 적용은 2027년 2월 1일에 시작한다.
출처: [Google Workspace Updates — MCP servers, CLI, and standardized usage tiers now available](https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html)

### Claude artifact를 Mac·Windows 앱으로 설치하는 "Install as app" 베타 — Anthropic (11/24)
Anthropic이 Claude artifact를 Mac·Windows 앱으로 설치하는 **Install as app**을 베타로 내놨다. Claude for Mac·Windows에서 모든 플랜에 순차 적용된다. HIPAA-ready 조직과 hybrid 배포에서는 쓸 수 없다. Team은 기본으로 켜져 있고(full access는 꺼짐), Enterprise는 owner가 켜야 한다. 권한은 Default, App permissions, Full computer access 3단계다. 설치한 앱의 요청은 플랜 사용 한도에 포함된다.
출처: [Claude — Turn artifacts into Mac and Windows apps](https://claude.com/resources/articles/install-as-app) · [Claude Help Center — Release notes](https://support.claude.com/en/articles/12138966-release-notes)

## 🏗️ 인프라

### Applied Digital, 하이퍼스케일러와 150MW·18년 임대 계약 — Applied Digital (11/23)
Applied Digital이 "tier-one investment-grade hyperscaler"와 150MW(critical IT 용량)·18년 임대 계약을 맺었다고 발표했다. 고객사 이름은 공개하지 않았다. 기본 계약 기간 매출은 약 54억 달러이고, 갱신 옵션을 모두 행사하면 총 33년간 약 127억 달러다. 이 계약으로 회사의 기본 계약 기간 임대 매출 합계는 410억 달러를 넘었다. 인도는 2028년 상반기에 시작될 예정이다.
출처: [Applied Digital — Applied Digital Secures New 150 MW, 18-Year Lease with Tier-One Investment-Grade Hyperscaler](https://ir.applieddigital.com/news-events/press-releases/detail/165/applied-digital-secures-new-150-mw-18-year-lease-with)

### Anthropic, Messages API를 Python에서 Rust로 이전한 과정 공개 — Anthropic (11/25)
Anthropic이 Messages API를 Python에서 Rust로 옮긴 과정을 엔지니어링 글로 공개했다. 이전 후 요청당 CPU 사용량은 약 70% 줄었고, 첫 토큰까지 걸리는 시간(중앙값)은 약 20% 줄었다. 서비스 중단은 없었다고 밝혔다. API 트래픽은 2024년 초부터 2026년 가을까지 약 1,800배 늘었다. 공개 트래픽은 2026년 9월에 Rust로 옮겨졌다.
출처: [Anthropic — Migrating our Messages API to Rust](https://www.anthropic.com/research/migrating-api-to-rust)

### FCC, SpaceX 궤도 데이터센터 위성 최대 100만 기 승인 — FCC · SpaceX (11/25)
미국 연방통신위원회(FCC)가 SpaceX의 궤도 데이터센터 위성 최대 100만 기 배치를 승인했다고 Decrypt와 The National이 보도했다. 두 매체는 궤도 데이터센터 위성군에 대한 미국의 첫 승인이라고 전했다. Decrypt는 이 위성군의 이름을 "Starmind"로 적었다. SpaceX는 1월에 신청서를 냈고, FCC는 2월에 심사를 시작했다. The National은 이번 승인이 데이터센터가 곧 궤도에 오른다는 뜻은 아니라고 전했다.
출처: [Decrypt — Elon Musk's SpaceX Gets FCC Approval to Launch AI Data Centers in Space](https://decrypt.co/383991/elon-musk-spacex-fcc-approval-ai-data-centers-space) · [The National — US gives SpaceX approval for data centres in space](https://thenationalnews.com/future/2026/11/25/data-centers-in-space)
