### U2-Flash 공개 — Unisound(雲知聲) (9/15)

### Gemini 3.8 Live · 3.8 Live Extended Thinking 출시 — Google (9/15)

Google이 근실시간 음성 에이전트용 네이티브 speech-to-speech 모델 두 종을 내놨다. **Gemini 3.8 Live**(`gemini-3.8-live`)는 규모·비용 효율에 맞춘 기본 모델로 시각 입력을 근실시간으로 처리하고 **97개 언어**를 대화 중 자동 감지·전환하며, 도구·API 호출을 대화를 끊지 않고 백그라운드에서 실행한다. **Gemini 3.8 Live Extended Thinking**(`gemini-3.8-live-extended-thinking`)은 고난도 작업용으로 생각하면서 동시에 말하며, 회사 발표 기준 Artificial Analysis Speech to Speech Quality Index **82.6으로 1위**, τ-Voice **68.6%**, Sierra τ-Voice-banking **35.1%**, Big Bench Audio **97.7%**를 기록했고 3.8 Live는 Speech Agent Arena 2위를 차지했다. Gemini API·Google AI Studio(Live API)에서 GA로 제공되며 가격은 **오디오 입력 분당 $0.005·출력 분당 $0.018**이고, Gemini Enterprise 비공개 프리뷰, Search Live, Workspace(Docs Live·Gmail Live·Keep Live)의 Pro·Ultra 구독자에게도 순차 적용된다. Agora·Fishjam·LangChain·LiveKit·Pipecat·Vercel·Vision Agents 등 플랫폼이 Live API를 지원하고 생성 오디오 전량에 SynthID 워터마크가 들어간다.
([Google Blog — Introducing Gemini 3.8 Live and 3.8 Live Extended Thinking](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-gemini-3-8-live-extended-thinking/) · [Google Blog — Build real-time voice applications with Gemini 3.8 Live and 3.5 Transcribe](https://blog.google/innovation-and-ai/technology/developers-tools/build-real-time-voice-applications-gemini-audio/) · [Gemini API Changelog — September 15, 2026](https://ai.google.dev/gemini-api/docs/changelog))

### Claude Code v2.1.271 릴리스 — Anthropic (9/14)

Claude Code Remote 세션(클라우드·자체 호스팅 러너)의 **fast mode**, 자동 모드+샌드박스에서 Bash·PowerShell·Monitor에 명령별 `allowed_domains`(명령에 필요한 호스트만 함께 검토·개방), 커스텀·플러그인 서브에이전트가 사용자·프로젝트·로컬 CLAUDE.md 없이 실행되게 하는 에이전트 frontmatter **`omitClaudeMd`**, `claude plugin install/update`의 `--accept-command <sha256>`, `modelPricing` 관리 설정의 1–10배 `multiplier`(내부 과금 마크업), `claude self-hosted-runner --drain-marker-file` 등이 추가됐다. 계정·조직·API 키 전환 후 캐시된 조직 정책이 재사용되던 문제, 워커 재시작 후 승인이 적용되면 클라우드 세션이 모든 서브에이전트 툴 호출을 거부하던 문제, Bash 권한 검사에서 옵션 뒤의 파일과 와일드카드 확장 파일이 누락되던 문제, compaction 후 백그라운드 명령이 중복 실행되던 문제, `--resume` 시 1M 컨텍스트(`[1m]`)가 빠지던 문제 등을 고쳤다. 자동 모드에서 스킬·슬래시 명령의 인라인 `!` 셸 명령은 분류기 대신 기본 모드 권한 규칙을 따르고, 서브에이전트의 결과 반환은 안전 분류기가 검토하는 전용 hand-back 호출로 바뀌었으며, Monitor 감시는 항상 마감(최대 30분, `-p`는 10분)을 갖고 `persistent` 옵션이 제거됐다. Pro 플랜의 동적 워크플로 기본 크기는 small로, medium 가이드는 15→10 에이전트로 조정됐다.
