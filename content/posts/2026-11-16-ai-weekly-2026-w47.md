## 🧠 모델 출시

### OpenAI GPT-6.2 Astra·GPT-6.2 Sol, GitHub Copilot에서 정식 제공 — GitHub (11/17)
GitHub가 OpenAI의 GPT-6.2 Astra와 GPT-6.2 Sol을 Copilot에서 정식 제공(GA)한다고 밝혔다. Astra는 에이전트 코딩·터미널 작업용이고, Sol은 복잡한 에이전트 코딩과 심층 코드 리뷰용이다. GitHub의 초기 테스트에서 Astra는 GPT-6 Astra보다 코드 리뷰 이슈를 더 많이 잡았고 토큰은 덜 썼으며, Sol은 GPT-6.1 Sol보다 실제 이슈를 거의 두 배 잡았다고 한다. Copilot Pro+, Max, Business, Enterprise에서 쓸 수 있고, 점진 배포 중이며, 요금은 제공사 정가 기준 사용량 과금이다.
출처: [GitHub Changelog — OpenAI's GPT-6.2 Astra and GPT-6.2 Sol now available](https://github.blog/changelog/2026-11-17-openais-gpt-6-2-astra-and-gpt-6-2-sol-now-available)

### MAI Code 2·MAI Code 2 Flash, GitHub Copilot에 추가 — GitHub (11/17)
GitHub가 코딩 모델 MAI Code 2와 MAI Code 2 Flash를 Copilot에 추가했다. MAI Code 2는 심층 디버깅·다중 파일 구현·리팩터링 같은 복잡한 작업용 범용 모델이고, Flash는 코드 설명·부분 수정 등 일상 작업용 경량 모델이다. MAI Code 2는 Pro·Pro+·Max·Business·Enterprise, Flash는 Free·Student 포함 전 플랜에서 쓸 수 있으며 둘 다 사용량 과금이다.
출처: [GitHub Changelog — MAI Code 2 and MAI Code 2 Flash in GitHub Copilot](https://github.blog/changelog/2026-11-17-mai-code-2-and-mai-code-2-flash-in-github-copilot)

### Gemini 4 Neon, GitHub Copilot에서 정식 제공 — GitHub (11/18)
GitHub가 Gemini 4 Neon을 Copilot에서 정식 제공(GA)한다고 밝혔다. 에이전트 코딩, 다단계 도구 사용, 지식 업무용 모델이다. Google에 따르면 품질은 Gemini 4 Carbon에 근접하면서 작업당 토큰 비용은 더 낮고, 응답 시작이 빠르며, 요청하지 않은 변경과 근거 없는 주장이 적다. Copilot Pro+, Max, Business, Enterprise에서 VS Code·Visual Studio·Copilot CLI·Copilot 코딩 에이전트·github.com·JetBrains·Xcode·Eclipse 등의 모델 선택기에서 쓸 수 있다. 점진 배포 중이며, 요금은 제공사 정가 기준 사용량 과금이다.
출처: [GitHub Changelog — Gemini 4 Neon in GitHub Copilot](https://github.blog/changelog/2026-11-18-gemini-4-neon-in-github-copilot)

## 🤖 AI 코딩 에이전트

### GitHub Copilot, Claude Opus 4.8·Opus 5·GPT-5.6 Terra 폐지 시행 — GitHub (11/16)
GitHub가 11/16부터 대부분의 Copilot 환경(Chat, 인라인 편집, ask·agent 모드, 코드 완성)에서 일부 모델을 폐지한다고 밝혔다. 대상은 Claude Opus 4.8, Claude Opus 5, GPT-5.6 Terra이며, 제안 대체 모델은 각각 Claude Opus 5.5, Claude Opus 5.5, GPT-6.1 Sol 또는 GPT-6 Luna다. Claude Opus 4.8은 연간 요금제 개인 구독자에게 계속 제공한다. Claude Opus 5는 모델 선택기에서 빠지지만 런타임 거부 폴백용으로는 남는다. Enterprise·Business는 관리자가 기본 모델 활성화를 끄거나 모델을 비활성화하지 않았다면 대체 모델이 자동으로 켜진다. GitHub는 이 폐지를 10/15에 예고했다.
출처: [GitHub Changelog — GitHub Copilot models deprecated on November 16, 2026](https://github.blog/changelog/2026-11-16-github-copilot-models-deprecated-on-november-16-2026)

### Claude Code 2.1.326: Code Mode를 agent teams와 함께 사용 — Anthropic (11/16)
Anthropic이 Claude Code **2.1.326**을 배포했다. agent teams를 켠 상태에서도 Code Mode를 켤 수 있게 됐고, 이미 Code Mode를 켠 경우 팀을 켠 세션은 Code Mode로 시작한다. `--allowedTools`·`--disallowedTools`·`--tools` 값에 완전한 규칙처럼 보이지 않는 항목이 있으면 시작 시 경고한다. `/status`에는 제공자나 `DISABLE_TELEMETRY` 같은 환경 변수가 기능을 끈 경우를 알리는 행이 추가됐다. `OTEL_RESOURCE_INCLUDE_HOST`로 OpenTelemetry 리소스 속성에 `host.name`·`host.id`를 넣을 수 있다(기본 꺼짐). 원본 편집 deny 규칙만 걸린 파일을 `cp`로 복사하지 못하던 문제 등도 수정됐다.
출처: [GitHub — anthropics/claude-code Release v2.1.326](https://github.com/anthropics/claude-code/releases/tag/v2.1.326)

### Claude Code 2.1.327: MCP JSON 표준입력 등록·/status 진단 확장 — Anthropic (11/17)
Anthropic이 Claude Code **2.1.327**을 배포했다. `claude mcp add-json <name> -`로 서버 JSON을 표준입력에서 읽어 토큰을 명령줄에 남기지 않을 수 있다. `/status`는 깨진 agent·skill·command·output style 파일, 키바인딩 오류, 일치하지 않는 hook matcher를 보여준다. `/install-github-app`은 저장소를 바꾸기 전에 확인을 받고, `/tui classic`이 기존 비전체화면 렌더러의 이름이 됐다. 프로젝트 범위 `claude mcp add`·`remove`가 `.mcp.json`의 다른 최상위 키(`$schema` 등)를 지우던 문제, `claude -p`가 모델 설정을 가져오다 멈추던 문제 등도 수정됐다.
출처: [GitHub — anthropics/claude-code Release v2.1.327](https://github.com/anthropics/claude-code/releases/tag/v2.1.327)

### GitHub Copilot Fusion 업데이트: 웹·Visual Studio 확대, Terminal-Bench 4.1 등재 — GitHub (11/17)
Copilot Fusion은 작업마다 모델을 골라 조합하는 Copilot 모델 선택기 옵션이며, 노력 수준(Max·High·Standard)만 고르면 된다. Fusion이 Stanford·Harbor·Laude Institute가 운영하는 Terminal-Bench 4.1 공개 리더보드에 올랐고, github.com·Visual Studio·GitHub Mobile 베타(iOS·Android)에서 쓸 수 있게 됐다. Fusion Max에 Claude Sonnet 5.5, High에 GPT-6.1 Terra, Standard에 MAI-Code-2가 추가됐다. GitHub에 따르면 Fusion Max의 해결률은 71.2%로 Opus 5.5·Fable 5.2보다 5.4%p 높고 비용은 각각 약 57%·88% 적다.
출처: [GitHub Changelog — GitHub Copilot Fusion updates](https://github.blog/changelog/2026-11-17-github-copilot-fusion-updates-more-availability-benchmarks-and-models)

### Copilot 브라우저 사용(browser use) 퍼블릭 프리뷰 — GitHub (11/17)
GitHub Copilot in Chrome 확장과 함께 Copilot이 브라우저를 직접 제어하는 browser use가 퍼블릭 프리뷰로 나왔다. 웹 앱 실시간 디버깅, 브라우저 테스트 자동화, 복잡한 웹 작업에 쓸 수 있으며 Copilot CLI·Copilot app·VS Code·JetBrains에서 지원한다. 확장의 설정에서 권한 수준을 관리한다.
출처: [GitHub Changelog — Let GitHub Copilot interact with your browser](https://github.blog/changelog/2026-11-17-let-github-copilot-interact-with-your-browser)

### Copilot에 Supabase·Box·Calendly 등 커넥터 8종 추가(퍼블릭 프리뷰) — GitHub (11/18)
GitHub 검증 MCP 서버로 Box, Buildkite, Calendly, ClickUp, Mixpanel, Supabase, Webflow, Wix를 Copilot에 연결할 수 있다. 기존 Slack·Figma·Sentry도 계속 지원한다. Copilot app, Copilot CLI(`/mcp`의 Connectors 탭), VS Code, github.com에서 한 번 연결하면 Copilot 전반에서 쓴다. 모든 Copilot 플랜에서 퍼블릭 프리뷰이며, Business·Enterprise는 관리자가 "Editor preview features" 정책을 켜야 한다.
출처: [GitHub Changelog — Connect Supabase, Box, Calendly, and more to Copilot](https://github.blog/changelog/2026-11-18-connect-supabase-box-calendly-and-more-to-copilot)

### 팀 단위 Copilot 맞춤 설정: 기본 Agent Plugin 지정 — GitHub (11/18)
조직 팀의 maintainer 또는 조직 소유자가 팀의 Customize Copilot 탭에서 승인된 Agent Plugin을 팀 기본 플러그인으로 지정할 수 있다. GitHub 저장소의 플러그인 마켓플레이스도 팀에 추가할 수 있다. 선택한 플러그인은 팀 직접 구성원의 VS Code·GitHub Copilot app·Copilot CLI에서 기본으로 켜지며, 하위 팀에는 상속되지 않는다. 엔터프라이즈·조직 정책이 팀 설정보다 우선한다. Copilot Business·Enterprise의 조직 팀에서 정식 제공(GA)이다.
출처: [GitHub Changelog — Customize GitHub Copilot for your team](https://github.blog/changelog/2026-11-18-customize-github-copilot-for-your-team)

### Claude Code 2.1.328: Bedrock·Foundry 등에서 Opus 4.6·Sonnet 4.6 auto mode — Anthropic (11/19)
Anthropic이 Claude Code **2.1.328**을 배포했다. Amazon Bedrock, Google Cloud의 Agent Platform, Microsoft Foundry, Claude apps gateway에서 Claude Opus 4.6과 Sonnet 4.6용 auto mode가 추가됐고, 권한 모드가 없는 대화형 세션은 auto mode로 시작한다. `mcp_tool` hook에 `"onFailure": "block"`이 추가돼 hook 호출이 실패하면 해당 동작을 막는다. OpenTelemetry exporter에 endpoint가 없어 데이터가 유실될 수 있으면 `/status`와 `claude doctor`가 알려 준다. 자체 호스팅 러너에는 `--repository-folder`, `--hook-label`, `--metadata key=value` 옵션이 추가됐다.
출처: [GitHub — anthropics/claude-code Release v2.1.328](https://github.com/anthropics/claude-code/releases/tag/v2.1.328)

### Claude Code 2.1.329: /tasks 확장·hooks 선언 위치 경고 — Anthropic (11/19)
Anthropic이 Claude Code **2.1.329**를 배포했다. 신뢰 대화상자가 폴더의 hooks가 선언된 위치를 알려 주고, `/tasks`에 현재 세션의 예약 작업·`/loop` 깨우기·goal·포크가 표시된다(x로 확인 후 중지). `/mcp` 서버 페이지에 원격 HTTP MCP 서버가 연결을 거부할 때의 JSON-RPC 오류 메시지를 보여 주는 "Server message" 행이, `/status`에는 자동 업데이트를 받지 못하는 관리형 마켓플레이스를 알리는 "Marketplace auto-update" 행이 생겼다. OpenTelemetry 이벤트·메트릭을 켠 상태에서도 Code Mode를 켤 수 있다. `~/.claude.json`이 기본값으로 초기화되던 문제, macOS 키체인 저장 실패 시 반복 로그아웃 문제 등도 수정됐다.
출처: [GitHub — anthropics/claude-code Release v2.1.329](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)

## 🛠️ 도구 · 벤치마크

### GitHub, AI Scan 저장소 일괄 시작(퍼블릭 프리뷰) — GitHub (11/16)
GitHub가 AI Scan을 최대 20개 저장소에 한 번에 시작하는 기능을 퍼블릭 프리뷰로 내놨다. AI Scan은 기본 브랜치의 보안 취약점을 찾으며, CodeQL이 지원하지 않는 언어도 대상이다. 결과는 CodeQL 알림과 함께 code scanning 백로그에 나타난다. 조직 수준 설정을 켤 때 저장소를 골라 시작하거나 조직의 code scanning 알림 페이지에서 시작할 수 있다. GitHub.com과 데이터 레지던시가 있는 GitHub Enterprise Cloud에서 쓸 수 있고, Copilot 라이선스는 필요 없다.
출처: [GitHub Changelog — Bulk start AI Scan for repositories](https://github.blog/changelog/2026-11-16-bulk-start-ai-scan-for-repositories)

### GitHub Copilot Evals 퍼블릭 프리뷰 — GitHub (11/17)
Copilot 설정의 skill, 커스텀 에이전트, MCP 도구가 어떻게 동작하는지 반복 가능한 테스트(eval)로 검증하는 도구다. 결과뿐 아니라 거친 경로도 확인하며, 변경 전후 실행을 비교할 수 있다. 로컬 평가 엔진 Vally를 쓰고 VS Code 확장, Copilot CLI 플러그인, Copilot app 마켓플레이스로 설치한다. Copilot Individual·Business·Enterprise에서 쓸 수 있다.
출처: [GitHub Changelog — GitHub Copilot Evals is now in public preview](https://github.blog/changelog/2026-11-17-github-copilot-evals-is-now-in-public-preview)

### Copilot 벤치마크 사이트에 Terminal-Bench-Science 0.1·Harnesses 보기 추가 — GitHub (11/17)
GitHub Copilot 벤치마크 사이트에 Terminal-Bench-Science 0.1과 Harnesses 보기가 퍼블릭 프리뷰로 추가됐다. Terminal-Bench-Science 0.1은 생명·물리·지구·수학·공학 분야 전문가가 작성·검토한 과학 연구 워크플로 과제로 에이전트를 평가한다. Harnesses 보기는 같은 모델·같은 추론 노력에서 Copilot CLI, Claude Code, Codex CLI를 해결률과 작업당 평균 비용으로 비교하며, 중간 추론 노력의 동일 모델 쌍만 포함한다.
출처: [GitHub Changelog — GitHub Copilot benchmarks site adds harness comparisons](https://github.blog/changelog/2026-11-17-github-copilot-benchmarks-site-adds-harness-comparisons)

### GitHub Team 조직에 보안 위험 평가 자동 실행 — GitHub (11/18)
GitHub Team 조직에서 코드 보안 위험 평가(코드 취약점)와 시크릿 위험 평가(노출된 자격 증명)가 자동으로 실행된다. 무료이며, 조직 관리자와 보안 관리자가 결과를 볼 수 있다. 발견된 시크릿·취약점은 배너 알림으로 알려주고 평가 검토 화면으로 연결한다.

## 🏗️ 인프라

### 미국 상무부, AI 칩 원격 접근 통제 강화 잠정 최종 규칙 — 미국 상무부 (11/16)
TechCrunch에 따르면 미국 상무부가 11/16 시행 예정인 잠정 최종 규칙(IFR)으로 AI 칩 수출 통제를 강화했다. 중국 등 제한 대상 국가 기업에 컴퓨트를 제공할 수 있는 전 세계 데이터센터로 AI 칩·서버를 수출·재수출·이전하려면 라이선스가 필요하다. 중개자를 통한 간접 접근도 포함하며, 총처리성능(TPP) 1,200만을 넘는 데이터센터·네트워크(H100·H200 약 750개 수준)가 대상이다. 말레이시아·싱가포르·인도네시아·태국·브라질로 가는 칩에도 라이선스 요건이 새로 생겼고(해당 국가의 미국 기업 앞 반입은 제외), 기존 데이터센터 운영자는 90일 안에 라이선스를 받아야 한다. 이 규칙은 2025년 1월 바이든 행정부의 AI Diffusion Rule을 폐지한다.
출처: [TechCrunch — US tightens AI chip export controls to deter Chinese companies from accessing compute remotely](https://techcrunch.com/2026/11/16/us-tightens-ai-chip-export-controls-to-deter-chinese-companies-from-accessing-compute-remotely/)
