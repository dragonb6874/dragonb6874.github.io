## 🧠 모델 출시

### GPT-Realtime-2.1 · 2.1-mini 출시 — OpenAI (7/6)

Realtime API용 저지연 음성·멀티모달 모델 **gpt-realtime-2.1**과 소형 추론 모델 **gpt-realtime-2.1-mini**를 공개했다. 캐싱 개선으로 p95 지연이 기존 대비 최소 25% 낮아졌고, 영숫자 인식·소음/침묵 처리·인터럽션(끼어들기) 동작이 개선됐다. 요금(100만 토큰): 2.1 오디오 입력 $32 / 출력 $64, mini 오디오 입력 $10 / 출력 $20.
([OpenAI — New Realtime models on the API](https://community.openai.com/t/new-realtime-models-on-the-api-gpt-realtime-2-1-and-gpt-realtime-2-1-mini/1385896))

### Claude Fable 5 주간 포함 한도 종료 → 사용 크레딧 전환 — Anthropic (7/7)

7/1 전 세계 재배포 이후 Pro·Max·Team·일부 Enterprise 플랜에서 **7/7까지 주간 사용 한도의 최대 50%**까지 Fable 5를 포함해 제공하던 임시 정책이 종료되고, 이후에는 **사용 크레딧(usage credits)** 으로만 이용 가능하다. Fable 5 요금은 100만 토큰당 입력 $10 / 출력 $50.
([Anthropic — Redeploying Fable 5](https://www.anthropic.com/news/redeploying-fable-5))

### GPT-5.6 Sol · Terra · Luna 정식 출시 — OpenAI (7/9)

OpenAI가 신규 3-티어 모델 패밀리 **GPT-5.6**를 정식 출시(GA)했다. 최고 성능 **Sol**(복잡한 코딩·보안 연구), 균형형 **Terra**(대량 업무), 저비용 **Luna**(요약·초안·자동화)로 나뉘며, 숫자는 세대, 이름은 능력 티어를 뜻한다. 다중 에이전트를 병렬로 조율하는 **ultra** 최고 설정도 함께 공개했다. ChatGPT·ChatGPT Work·Codex·API에서 이용 가능(24시간 내 전 세계 순차 배포). 요금(100만 토큰): Sol 입력 $5 / 출력 $30, Terra $2.50 / $15, Luna $1 / $6.
([OpenAI — GPT-5.6](https://openai.com/index/gpt-5-6/))

## 🤖 AI 코딩 에이전트

### Claude Code 2.1.205 업데이트 — Anthropic (7/8)

Claude Code **2.1.205**가 에이전트 워크플로·auto 모드 안전성·Windows 안정성을 개선했다. 세션 transcript 파일 변조를 막는 auto 모드 규칙 추가, `--json-schema`가 잘못된 스키마에서 비정형 출력을 내던 버그 수정, `--max-turns` 한도에서 메시지 유실 수정, Windows worktree 삭제 시 NTFS junction 밖 파일까지 지우던 문제 수정 등이 포함됐다.
([Anthropic — claude-code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md))

### Codex, ChatGPT 데스크톱 앱 통합 · GPT-5.6 Computer Use 가속 — OpenAI (7/9)

OpenAI가 코딩 에이전트 **Codex**를 macOS·Windows용 ChatGPT 데스크톱 앱에 통합했다. Markdown/코드 직접 편집, 사이드바 GitHub PR 리뷰, 다중 저장소 프로젝트를 지원한다. 같은 날 **GPT-5.6로 Computer Use 속도를 개선**하고 작업 진행 상황 가시성을 높였다. 앞서 7/8 CLI 0.143.0에서는 Amazon Bedrock용 Sol·Terra·Luna와 "max" 추론 설정을 추가했다.
([OpenAI — Codex changelog](https://developers.openai.com/codex/changelog))

## 🛠️ 도구 · 벤치마크

### ChatGPT Enterprise 사용량 분석·지출 관리 기능 추가 — OpenAI (7/8)

OpenAI가 ChatGPT Enterprise에 **사용량 분석(usage analytics)** 대시보드와 **지출 관리(spend controls)** 기능을 추가했다. 관리자가 Global Admin Console 한 화면에서 사용자·제품·모델별 크레딧 소비를 세분화해 보고 예산을 설정할 수 있으며, ChatGPT와 Codex 크레딧 사용을 통합 조회한다.
([OpenAI — New usage analytics and updated spend controls for enterprises](https://openai.com/index/chatgpt-enterprise-spend-controls/))

### ChatGPT Work 에이전트 출시 — OpenAI (7/9)

OpenAI가 앱·파일·워크플로 전반의 맥락을 모아 시트·슬라이드·문서·웹앱 등 완성물을 만들어 주는 업무 에이전트 **ChatGPT Work**를 공개했다. Codex 기술이 내장돼 복잡한 프로젝트를 작은 단계로 쪼개 수 시간 동안 독립 수행한다. GPT-5.6 기반이며, 웹·모바일은 Pro·Enterprise·Edu부터, 데스크톱 앱(Mac·Windows)은 무료 포함 전 플랜에서 즉시 이용 가능하다.
([OpenAI — ChatGPT for your most ambitious work](https://openai.com/index/chatgpt-for-your-most-ambitious-work/))

## 🏗️ 인프라

### Anthropic, TeraWulf와 190억 달러 데이터센터 임대 계약 — Anthropic (7/6)

Anthropic이 TeraWulf와 **20년간 190억 달러** 규모의 AI 데이터센터 임대 계약을 체결했다. 켄터키주 호크스빌(Hawesville)의 옛 알루미늄 제련소 부지(790에이커)에 건설하며, 완전 가동 시 **401메가와트** 규모다. 초기 용량은 2027년 하반기, 완전 가동은 2028년 예정.
([SiliconANGLE — Anthropic inks $19B AI data center lease with TeraWulf](https://siliconangle.com/2026/07/06/anthropic-inks-19b-ai-data-center-lease-terawulf/))

### Bespoke Labs, 4,000만 달러 투자 유치 — Bespoke Labs (7/6)

AI 에이전트 학습용 강화학습 환경·인프라를 구축하는 Bespoke Labs가 **총 4,000만 달러**(Wing VC 주도 Series A 3,175만 달러 + 시드 825만 달러)를 유치했다. 장기 과제(long-horizon) 에이전트를 학습·평가·개선할 현실적 환경을 만드는 데 자금을 투입한다. 2024년 Mahesh Sathiamoorthy·Alex Dimakis가 창업.
([SiliconANGLE — AI post-training startup Bespoke Labs raises $40M in funding](https://siliconangle.com/2026/07/06/ai-post-training-startup-bespoke-labs-raises-40m-funding/))
